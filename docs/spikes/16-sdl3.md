# Spike 16: the SDL3 runtime's base

Added in phase S, for [ADR 0012](../adr/0012-sdl3-runtime.md).

Why: before the presentation moves from Defold to SDL 3.4.18, the plan needs evidence on every platform for:
- what GLES 3.0 / WebGL2 gives the index-space pipeline;
- what texture uploads and draw calls cost without Defold;
- whether SDL3_mixer plays the interface's sounds with DirectSound's gains;
- whether SDL 3.4's PNG loader keeps 8-bit indices;
- whether the web build keeps files in IndexedDB.

Code: deleted on 2026-11-13 (nothing built or ran it, and its `build.sh` still read the `generated/` folder phase D removed); this page stays as ADR 0012's evidence. The last version is `spikes/16-sdl3/` at commit a19f982 (`spike.c`, `CMakeLists.txt`, `make_assets.py`, `build.sh macos|web|ios-sim`, `android.sh run`).

Each check printed `SPIKE <name> PASS|FAIL <details>`, and a run ended with `SPIKE DONE pass=<n> fail=<m>`.

## Checks

| Check | What it proves |
|---|---|
| `context` | GLES 3.0 / GL 4.1 core context; an R8 colour target with a 24-bit depth attachment is complete; at least 4 vertex texture units |
| `r8_texel_fetch` | `texelFetch` of an R8 texture into an R8 target, read back: all 307,200 indices exact |
| `vertex_fetch_depth24_keep` | 64 quads placed by an RGBA32F data texture read in the vertex shader (the `mesh_texture` scheme of ADR 0002), drawn in a shuffled order with depth GREATER, ranks 2⁻²⁰ apart (beyond 16-bit depth), after a switch to another target and back: the highest rank wins at every pixel, so GL keeps a target's contents and depth (no restore pass) |
| `palette_uniform` | the palette pass through a 256-entry uniform array into the default framebuffer, read back exact |
| `gl_errors` | no GL error after the checks |
| `png_gray8`, `png_palette8` | `SDL_LoadPNG_IO` returns 8-bit grayscale and 8-bit paletted PNGs as `SDL_PIXELFORMAT_INDEX8` with the exact indices |
| `audio_ogg_stereo` | an OGG from the sound packs, predecoded by SDL3_mixer (stb_vorbis), played with DirectSound's volume −600 and pan +2000 as gains (`MIX_SetTrackGain`, `MIX_SetTrackStereo`); the stop callback comes at the sound's length |
| `idbfs` (web) | a file written under an IDBFS mount and synchronised is there after a reload |
| `bench_upload_tick_frame` | on every frame: the product's image data (RGBA32F 256×73) and a 640×160 R8 canvas rectangle uploaded with `glTexSubImage2D` (mean, p95, max) |
| `bench_4000_draws` | 4000 draw calls a frame, each with its own uniforms (Defold allowed 1024 render commands) |
| `bench_frame_vsync_off` | the whole frame with both, vsync off |

## Results (2026-10-25)

| Check | macOS (M4 Max, GL 4.1 over Metal) | Web (Chromium in the browser pane, WebGL2) | iOS Simulator | Galaxy Z Fold7 |
|---|---|---|---|---|
| context | pass: depth 32 bits, max texture 16384, 16 vertex units | pass: depth 24 bits, max texture 16384, 16 vertex units | builds; not run (no simulator runtime) | pass: GLES 3.2 (Adreno 830), depth 24 bits, max texture 16384, 16 vertex units |
| r8_texel_fetch, vertex_fetch_depth24_keep, palette_uniform, gl_errors | pass, 0 mismatched | pass, 0 mismatched | — | pass, 0 mismatched |
| png_gray8, png_palette8 | pass, INDEX8 exact | pass, INDEX8 exact | — | pass, INDEX8 exact |
| audio_ogg_stereo | pass: 2342 ms expected, stop at 2356 ms | pass when the pane is visible (2355 ms); a hidden pane gets no audio progress (stop after 85 s) | — | pass: stop at 2322 ms |
| idbfs | — | pass: the counter written by the first load (−1 → 0) read by the second | — | — |
| upload at the tick (mean / p95 / max) | 0.065 / 0.080 / 0.139 ms | 0.017 / 0 / 1 ms (the page's timer has 1 ms steps) | — | 0.061 / 0.165 / 0.496 ms |
| 4000 draws | 2.09 / 2.21 / 2.85 ms | 0.31 / 1 / 1 ms (CPU side only) | — | 0.80 / 1.14 / 2.28 ms |
| frame, vsync off | 3.83 / 6.12 / 40.5 ms (the first frames after the window opened) | 5.27 / 6 / 7 ms | — | 2.77 / 5.03 / 6.33 ms |

For comparison, spike 15 measured one `set_texture` of a 256×1 palette at 0.44 / 0.60 / 1.45 ms on the same Mac and 1.67 / 5.51 / 6.14 ms on the Fold7, through Defold's Vulkan backend. On the Fold7 the spike's two uploads of a tick frame (an RGBA32F 256×73 texture and a 640×160 R8 rectangle) cost 0.061 / 0.165 / 0.496 ms through GLES 3.2, so the rule of one upload per frame, never on the tick's frame (ADR 0002) has no cause left. A frame of 4000 draw calls stays under 1.2 ms at p95 on the device, against the 1024 render commands Defold allowed.

## Notes

- **Stack size on the web.** The first web run crashed with "memory access out of bounds" in `glGetString`. The cause was emscripten's default 64 KB stack: a 64 KB local buffer was inlined into `SDL_AppInit`'s frame. The spike links with `-sSTACK_SIZE=1048576`, which the runtime needs too.
- **Audio in the browser.** Audio progresses only in a visible page; Chromium in the pane allowed playback without a gesture. The runtime resumes the mixer on the first input (ADR 0012).
- **ScriptProcessorNode.** SDL3's emscripten audio uses it, and Chromium warns that it is deprecated. Playback is correct.
- **Android build.**
  - libSDL3.so is shared on Android because SDLActivity loads it before libmain.so.
  - The SDK's CMake 3.22 is too old, so `android.sh` points Gradle at the host's CMake and Ninja (`local.properties` `cmake.dir`).
  - The only JDK on the host is 27, so `android.sh` uses the cached Gradle 9.7.1 and Android Gradle plugin 9.1.1, which run on it, offline.
- **iOS.**
  - The GLES 3 header is `<OpenGLES/ES3/gl.h>` (with `GLES_SILENCE_DEPRECATION`), not Khronos' `<GLES3/gl3.h>`.
  - The simulator build links (Xcode 27.1, iOS 15 deployment target).
  - Running it waits for an iOS Simulator runtime: the host's CoreSimulator was older than Xcode's until `xcodebuild -runFirstLaunch`, and no runtime is installed (`xcodebuild -downloadPlatform iOS`).
- **Windows GL loading** is left to stage S4: the spike links GL directly on macOS, Linux, iOS, Android and the web.
