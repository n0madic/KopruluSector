# Implementation status

The traceability ledger of `IMPLEMENTATION_PLAN.md` §6 and §8. Each implemented contract is linked to its research domain (R01–R37 of the [completion ledger](research/completion-ledger.md)), its evidence, the Koprulu code and tests, and the next gate it has not passed. State as of phase 5, items 5.0–5.5 done and 5.6 in progress (2026-10-17).

The marks are independent axes, not one scale (§8):
- `original-static`: data or instructions decoded;
- `original-isolated`: the original function or chain ran to its return on declared inputs;
- `implemented` / `fixture-verified`: Koprulu code exists and passes the named tests;
- `original-game-observed`: compared with a full-game observation of the original;
- `runtime-verified`: checked in running Defold;
- `approximation`: a deliberate difference with its ADR.

No mission has a full gameplay status yet: the initial state of every mission equals the original, its trigger state included, and five campaign missions without AI scripts (`terran/tutorial`, `terran/terran01`, `terran/terran02`, `terran/terran04`, `zerg/zerg05`) run idle for 2,000 steps equal to the original at every step, their own triggers and trigger trace included ([phase 5](phase5.md)); the other missions stop at their first AI script (plan phase 7) or economy mechanism (plan phase 6).
