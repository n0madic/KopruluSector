# P35: Sound engine, sound/speed options, command-card buttons and the console command and status panels

This package covers `0x49d950`–`0x4a2570`: the tail of `snd.cpp`, the objects between `snd.cpp` and `statcmd.cpp`, `statcmd.cpp`, the object after it, and the first part of `statdata.cpp`. Its 175 atlas functions form six groups.

1. **Sound engine** (`0x49d950`–`0x49eca0`, `snd.cpp`). DirectSound start-up and shutdown, the 1,144-entry sound cache with its background loader thread and second-chance eviction, the eight playback channels with priority preemption, positional/volume playback entry points, streamed (DDA) sounds, music/effects volume application and the mute toggles.
2. **Sound and speed options dialogs** (`0x49ed30`–`0x49f3c0`). `rez\snd_dlg.bin` (music/effects sliders, four sound-option checkboxes) and `rez\spd_dlg.bin` (game speed, mouse and key scroll sliders, CPU throttle checkbox), opened from the in-game options menu of [P27](p27.md).
3. **Command-card button conditions and actions** (`0x49f410`–`0x4a04c0`). These are the condition callbacks (visible / enabled / disabled) and two actions referenced by the 250 button sets at `0x50ae98`. The full table is resolved in the appendix.
4. **Research and upgrade in-progress bitsets** (`0x4a04e0`–`0x4a05f0`), covered by [research/upgrade](../native-research-upgrade.md) and [DAT requirements](../native-dat-requirements.md).
5. **Command card** (`0x4a0620`–`0x4a1ae0`, `statcmd.cpp`, `rez\statbtn<race>.bin`). Button population from the selected unit's button set, multi-selection set merging, the current-order highlight, hotkeys, the cost tooltip, button drawing and the progress bar.
6. **Status panel support** (`0x4a1ae0`–`0x4a2570`, `statdata.cpp`, `rez\statdata.bin`). Dialog loading, hover/tooltip dispatch, the twelve multi-selection boxes and the small helpers used by the layouts in [P36](p36.md).

## Sound data model

| Address | Meaning |
|---|---|
| `0x6a61d0 + 16·id` (id < `0x478` = 1,144) | Sound cache record: `+0` u32 data size in bytes, `+4` u32 negated tick of the last start (`−GetTickCount()`; a load stores `0x51 − GetTickCount()`), `+8` u32 duration in ms (`0x49da70`), `+0xc` `IDirectSoundBuffer*` (null = not loaded). |
| `0x51c270[id]` | `sfxdata.dat` file name, resolved to a `sfxdata.tbl` string pointer by `0x49dac0` (null = no file). Paths are formatted as `sound\%s`. |
| `0x51d8c8[id]` | `sfxdata.dat` flags byte with runtime bits: `0x01` preloaded/permanent (size not counted, never evicted), `0x02` one sound per unit type, `0x04` recently used (second-chance bit), `0x08` load queued, `0x10` one instance per sound ID, `0x20` cannot be preempted. |
| `0x51d450[id]` | `sfxdata.dat` priority byte. |
| `0x6aa990 + 24·c` (8 channels, end `0x6aaa50`) | Channel: `+0` buffer, `+4` u16 unit type (`0xffff` none), `+6` flags (copy of the sound flags; bit `0x08` = waiting for the loader), `+7` priority, `+8` release-on-reuse byte (1 for a duplicated buffer), `+0xc` sound ID, `+0x10` volume, `+0x14` pan. |

| `0x6d3130…` | Options block (see [P27](p27.md)): `0x6d3130` game speed, `0x6d3134` mouse scroll speed, `0x6d3138` key scroll speed, `0x6d313c` music volume 0–100, `0x6d3140` effects volume 0–100, `0x6d3148` sound option bits, `0x6d314c`/`0x6d3150` multiplayer mouse/key scroll speeds. |

**Attenuation table `0x4efc00[100]`** (s32, hundredths of a dB, DirectSound volume). Effects use index `(0x6d3140 × 99) / 100` (signed). Music uses `0x4efbfc[vol]`, i.e. `0x4efc00[vol − 1]` for vol 1–100 (vol 0 means "music off", see `0x49ea60`). Values for index 0–99: −4000, −3396, −3044, −2794, −2602, −2442, −2308, −2192, −2090, −2000, −1917, −1840, −1772, −1706, −1646, −1590, −1539, −1489, −1442, −1396, −1354, −1315, −1275, −1238, −1204, −1170, −1137, −1104, −1075, −1044, −1017, −988, −961, −937, −910, −887, −862, −840, −816, −794, −774, −752, −733, −713, −692, −674, −654, −636, −618, −602, −583, −566, −551, −535, −519, −502, −488, −473, −458, −442, −429, −415, −401, −386, −374, −359, −346, −333, −322, −308, −297, −285, −273, −260, −248, −238, −227, −214, −203, −192, −183, −172, −160, −151, −141, −131, −119, −111, −101, −90, −80, −72, −63, −52, −43, −35, −26, −20, −20, −20.

**Sound life cycle.** A play request (`0x49e740`/`0x49e780` → `0x49e4e0`) applies the exclusivity rules, then either starts a cached buffer immediately (`0x49e620`) or, when the sound is not loaded, reserves a channel and wakes the loader thread (`0x49e000`). The thread (`0x49e090`) reads `sound\<file>` from the MPQs, creates a static buffer, and starts it if the channel still waits. When the cache total exceeds the limit, `0x49e930` releases idle buffers with a clock-hand second-chance scan. Sound selection, the request volume and its RNG use live in the callers ([P15](p15.md), [audiovisual](../native-audiovisual.md#sound-choice-ownership-and-initialization)).

## Command-card data model

**Button record** (20 bytes): `+0` u16 position (1–9), `+2` u16 icon (`cmdicons.grp` frame), `+4` condition, `+8` action, `+0xc` u16 condition value, `+0xe` u16 action value, `+0x10` u16 enabled string, `+0x12` u16 disabled string (stat_txt IDs; 0 = none).

**Button set table `0x50ae98[250]`** (12 bytes): `+0` u32 button count, `+4` button array, `+8` u32 linked set (`0xffff` none; set 16 → 1 and set 19 → 2, which makes Sarah Kerrigan and Jim Raynor (Vulture) merge with Ghost and Vulture). Sets 0–227 belong to unit types; 228 = empty; 229 targeting (Cancel → `0x4a04b0`); 230 placement (Cancel → `0x4a04c0`); 231–237 construction/morph cancel and special sets; 238–243 Drone/SCV/Probe basic and advanced build menus; 244 generic mixed group; 245 workers; 246 cloakers; 247 burrowers; 248/249 replay controls ([P28](p28.md)). The complete contents are in the appendix.

**Calling conventions.** A condition is called by `0x4a1080` with `ECX` = **low byte** of the condition value (zero-extended), `EDX` = local player `0x508d50` (byte), stack = status unit `0x6ab4c4`, `ret 4`. It returns 0 (hide), 1 (enabled) or a negative value (shown disabled; the requirement error in `0x6be654` selects the text). An action is called by `0x4a0660` with `CX` = action value and `DL` = Shift state `0x665e68`. Conditions that inspect the whole selection walk the 12 slots `0x6ab4c8[0..11]` (null slots skipped); `0x6ab4c0` is the selection count.

## Entries

### 0x0049d950 `LoadWavSoundBuffer` — read a WAV file into a new static DirectSound buffer
- Module: snd.cpp · Relevance: audio
- Status: specified
- Signature: `__fastcall`, `ECX` = file path, `EDX` = optional `u32*` that receives the data size; returns `IDirectSoundBuffer*` or 0.
- Behavior: Reads the whole file with `0x444990` (optional, line `0xfa`). Missing file → 0. Empty file → free, 0. Otherwise parses it with `0x49d830` (RIFF/WAVE, see [audiovisual](../native-audiovisual.md#riffwave-parsing-and-retained-failure-mutations)); failure → free, 0. Creates a buffer through `IDirectSound::CreateSoundBuffer` (vtable `+0xc`) with a 20-byte descriptor {size `0x14`, flags `0xc2` (static, volume and pan control), bytes = data length, format = parsed `WAVEFORMATEX`}. On failure → 0. Locks the whole buffer (`+0x2c`, offset 0, length = data length), copies the first locked region with `memcpy`, unlocks (`+0x4c`). A failed lock releases the buffer and returns 0. On success stores the data length through `EDX` when non-null. The file memory is always freed (line `0x139`).
- Callers/callees: `0x49d900` (sound ID → `sound\<name>`, size into the cache record), `0x49e300`.

### 0x0049da70 `GetSoundBufferDurationMs`
- Module: snd.cpp · Relevance: audio
- Status: covered
- Signature: `__fastcall`, `ECX` = sound cache record; returns u32 ms.

### 0x0049db60 `AcquireSoundChannel` — pick a free or preemptible channel
- Module: snd.cpp · Relevance: audio
- Status: specified
- Signature: `CL` = priority of the new sound; returns the channel index 0–7 or −1.
- Behavior:
  1. For c = 0…7: a channel with flag `0x08` (waiting for the loader) is skipped. A channel whose buffer is null becomes the candidate. A channel with a buffer calls `GetStatus` (vtable `+0x24`); if the status is not 1 (playing) the buffer is released when `+8` ≠ 0, the pointer is cleared and the channel becomes the candidate. A playing channel is kept. The scan always visits all eight channels, so **the last free channel wins** and every finished buffer is reclaimed.
  2. With a candidate, return it.
  3. Otherwise preemption: for c = 0…7 in order, a channel that is not waiting, has a buffer, lacks flag `0x20`, and whose priority `+7` is **strictly below** the running minimum (initially the new priority) becomes the candidate and lowers the minimum. Equal priorities keep the earlier channel.
  4. No candidate → −1. Otherwise `Stop` (`+0x48`) the buffer; if `+8` ≠ 0 `Release` it, else `SetCurrentPosition(0)` (`+0x34`); clear `+0`; return the index.
- Prior evidence: [audiovisual](../native-audiovisual.md#eight-channels-and-queued-sound-policy) executed all 256 queued/null masks; the playing-buffer paths are specified here from the code.

### 0x0049de30 `InitializeDirectSound`
- Module: snd.cpp · Relevance: audio
- Status: specified
- Signature: `__fastcall`, `ECX` = main window, `EDX` = error record {u32 error code, u32 network.tbl message, `char*` failing API}; returns 1 on success.
- Behavior: Returns 1 at once if the device `0x6aa954` exists. Sets the record to {0, `0x8a`, null} and zeroes the channel table (`0xc0` bytes). Loads `dsound.dll` if `0x6aa950` is null (failure: message `0x85`, `GetLastError`, "LoadLibrary"). Then, stopping at the first failure:
  1. `0x49d6b0`: `DirectSoundCreate` through `GetProcAddress` (a missing export stores `GetLastError` and "GetProcAddress"); while it returns `DSERR_ALLOCATED` (`0x8878000a`) and the retry count `0x5093d4` > 0, `Sleep(1000)`, decrement and retry. Failure stores the code, "DirectSoundCreate", and message `0x87` for `DSERR_ALLOCATED`.
  2. `0x49d610`: `SetCooperativeLevel(window, 2)` (priority), falling back to level 1; failure → "SetCooperativeLevel".
  3. `0x49d760`: primary buffer (flags 1) into `0x6aa958`; failure → "CreateSoundBuffer".
  4. `0x49d660`: primary format PCM, 2 channels, 22,050 Hz, 88,200 bytes/s, block 4, 16 bits (result ignored).
  5. `SFileDdaInitialize(device)`, `0x6a61c9 = 1`; `SVidInitialize(device)`, `0x6a61ca = 1`.
  6. `LoadUiClickSound` `0x49e300`; `InitDefaultVolumes` `0x49dfa0`.
  7. Cache limit `0x5093c4` = registry `Starcraft\Sound Memory Cache` (`SRegLoadValue`); missing → `0x400000`; present → max(value, `0x100000`) unsigned. `0x6aa95c = 0`.
  8. `CreateEventA(0, auto-reset, non-signaled, 0)` → `0x6aa960`; `0x6aa968 = 1`; `_beginthreadex(0, 0, 0x49e090, 0, 0, &0x6aaa54)` → `0x6aa964`; `0x6a61c8 = 1`; return 1.
  Any failure calls `ShutdownDirectSound` `0x49eae0` and returns 0.
- Callers/callees: `0x465bc0` (skipped with the `nosound` option).

- Module: snd.cpp · Relevance: audio

### 0x0049e090 `SoundLoaderThread`
- Module: snd.cpp · Relevance: audio
- Status: specified
- Signature: thread procedure (`_beginthreadex`), one ignored argument, `ret 4`; returns 0.
- Behavior: Waits on the event (infinite), then loops while the running flag `0x6aa968` ≠ 0:
  1. `added = 0`. For each channel c = 0…7 with flag `0x08`: `id` = `+0xc`; record `+4 = 0x51 − GetTickCount()`. If `0x51c270[id]` is non-null: read `sound\<name>` (`0x444990`, line `0x2e1`); if it exists, is non-empty and parses (`0x49d830`), store the data size in record `+0`, create a static buffer (flags `0xc2`) into record `+0xc`, lock, copy and unlock as `0x49d950`. Lock failure releases the buffer; any creation failure leaves `+0xc` = 0. After a successful copy: unless flag `0x01`, `added += size`; record `+8` = `0x49da70`(record). If the channel still has flag `0x08`, it sets volume (`+0x10` − `0x6aa96c`) and pan (`+0x14`), calls `Play(0, 0, 0)` (result ignored), and stores the channel buffer, `+8 = 0`, `+6` = sound flags and `+7` = priority.
  2. In every case the file memory is freed (line `0x337`), and both the sound flag `0x08` and the channel flag `0x08` are cleared.
  3. If `added` ≠ 0, adds it to `0x6aa95c` inside critical section `0x6aa970`.
  4. Waits on the event again.
- Notes: A request whose channel lost its `0x08` flag meanwhile (`StopAllSounds`) is loaded but not started. The cache-limit check happens in `0x49e000` before the bytes are counted.

### 0x0049e4e0 `PlaySoundInternal` — exclusivity rules, then play or queue
- Module: snd.cpp..statcmd.cpp · Relevance: audio
- Status: specified
- Signature: `ECX` = sound ID, `EDX` = attenuation, stack [pan, unit or 0]; `ret 8`; returns 1 if started or queued.
