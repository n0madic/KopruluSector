# P15: Game loop, tileset loading, game-screen layer, unit sound feedback and game templates

This package covers `0x444930`–`0x448530`: the tail of `gamedata.cpp`, `gameloop.cpp`, `gamemap.cpp`, an unnamed object between `gamemap.cpp` and `gametype.cpp` (game-screen drawing and unit sound feedback) and most of `gametype.cpp`. Its 122 functions fall into six groups.

1. **File helpers** (`0x444930`–`0x444ca0`). Storm wrappers that finish the `gamedata.cpp` set documented in [P14](p14.md): bitmap and whole-file loaders, asynchronous read starters and a null-tolerant free.
2. **Game loop** (`0x444cc0`–`0x445520`). `0x445310` runs one game from its first frame to exit. Its inner loop `0x4451f0` pumps messages, scrolls, receives network turns, runs frames through `0x444e30` and presents the screen. `0x444e30` performs the per-frame sequence: turn gate `0x444cc0`, the object step `0x445070` or the paused path `0x444de0`, then the trigger scheduler. The speed tables live here.
3. **Map and tileset** (`0x445540`–`0x445a30`). Tileset file loading (`.wpe .vf4 .cv5 .grp .vx4 .vr4`), the terrain buffers, their release, map strings, terrain height and the initial screen position.
4. **Game-screen layer** (`0x445d70`–`0x446050`). Screen layer 5 (the 640×400 map view), its draw callback `0x445ea0`, the dirty-cell blitter `0x445f80` and two command-mode mouse handlers.
5. **Unit sound feedback** (`0x446080`–`0x447190`). Stereo pan and distance volume, the positional sound gates `0x446940`/`0x446a20`, the Yes/What/annoyed selectors, advisor and worker error voices, the under-attack notice and the shared cooldowns.
6. **Game templates and victory setup** (`0x447220`–`0x448530`). The `Templates\templates.lst` list, queries on the current template stored in the game header, starting resources, CTF flag beacons and the melee/victory trigger files.

## Shared data and tables

**Speed tables.** `0x503360[7]` holds milliseconds per frame, slowest to fastest. The static image is `{167, 111, 83, 67, 56, 48, 42}`, and `0x445110` overwrites it at game/replay start. `0x50337c[7]` = `{501, 333, 249, 201, 168, 144, 126}` (3× the static speeds) is the resynchronization limit used by `0x4451f0`. `0x50335c` holds the maximum frames per call of `0x444e30`: static 1, set to 1 or 10 by `0x481040`. The speed index is `0x6d3130`. Frames per network turn are in `0x666404[7]` (`0x445110`/`0x445470`).

**Loop state.** `0x6663ed` game-running byte; `0x666420` exit code WORD; `0x6663f8` next-frame tick; `0x6663fc` frames left in the current turn; `0x666400` waiting-for-turn byte; `0x66642c` wait start, later the elapsed wait; `0x6663f4` negated tick of the last scroll step; `0x6663f0` exit reason of `0x444e30`; `0x666424` frames stepped by the last `0x444e30`; `0x666428` last palette-cycle tick; `0x6663e4` countdown of the 100-step periodic refresh; `0x6663ec` periodic-refresh byte; frame counter `0x52651c`; pause flag `0x67517c` (`0x47cb60`); application-active flag `0x66fd24`; replay flag `0x67cc90`; replay-paused flag `0x67cc7c`.

**Tileset names** `0x503398[8]` (index WORD `0x5264bc`): badlands, platform, install, AshWorld, Jungle, Desert, Ice, Twilight.

**Screen layer 5** (game view) is record 5 of the 20-byte layer array at `0x6d0b90`. Its fields are `+0` enable byte `0x6d0bf4`, `+1` flags `0x6d0bf5` (bit 0 = full redraw requested, bit 1 = partial redraw happened), `+2/+4` x/y (`0x6d0bf6`), `+6/+8` width 640 and height 400 (`0x6d0bfa`), `+0xc` `0x6d0c00` and the draw callback `+0x10` = `0x6d0c04`. `0x4cadf0(CL = layer)` sets the layer's flag bit 0 and marks its rectangle in the screen dirty map (`0x4cac50`). The game-view rectangle `0x666430` = {0, 0, 639, 399}. Dirty-cell grid `0x6d06d0`: 40 columns × 25 rows of 16×16-pixel cells.

**Sound data.** sfxdata.dat arrays: preload flags `0x51d8c8[1144]` (bit 0), a signed WORD per sound at `0x51dd40` (column 4, named "race" by some editors), added in ms to talking durations here, and minimum volume `0x51e630[1144]`. Cached durations: `0x6a61d8 + 16*id` (`0x49db30`). units.dat sound ranges (WORD per type): What start `0x522038`, What end `0x522200`, annoyed start `0x5223c8`, annoyed end `0x5224a0`, Yes start `0x522578`, Yes end `0x522650`; "ready" sound `0x521f60`. The annoyed and Yes ranges exist only for types < 106 (`0x6a`). Sound device present: `0x6d3140`. Sound options `0x6d3148`: bit 0 gates advisor/notification voices, bit 1 unit responses, bit 2 building sounds, bit 8 (`0x100`) shows tips at game start. The local race byte is `0x5264c2`.

**Sound state.** `0x667280` quiet flag (volumes ÷5; `0x446930` sets it, `0x446fd0` clears it); `0x66697c` previous random sound; `0x66726c` last unit selected for a sound; `0x667270` click sequence count; `0x667274` selection-sound cooldown; `0x667278` a cooldown with no writer besides reset and decrement; `0x66727c` under-attack cooldown; `0x667284` two-call divider; unit `+0x87` per-unit attack-notice cooldown; `0x666978` preload-lists built.

**Sound preload lists** `0x5033b8[race]`: Zerg `0x666980` = IDs 1–113 then 755–967; Terran `0x666c10` = 1–113 then 174–472; Protoss `0x666f50` = 1–113 then 473–754. Each list ends with 0.

**Common "advisor" playback pattern** (used by `0x4461f0`, `0x446760`, `0x446b70`, `0x446e90`, `0x447060`): when the sound ID is nonzero and `0x6d3140` ≠ 0, `vol = max(99, minVol[id])` (signed), divided by 5 (signed) when `0x667280` ≠ 0. If `vol > 10`, `0x49e780(ECX = id, EDX = vol, stack [pan 0, unit 0])` plays it. **Talking request**: `0x4a7200(ECX = unit, EDX = floor(dur/1000)*1000 + (s16)0x51dd40[id], stack [camera flag, minimap color, id])`, where `dur = 0x49db30(id)` and the floor is unsigned.

### 0x00444930 `LoadBitmapAllocOrDie` — `SBmpAllocLoadImage` into a bitmap descriptor
- Module: gamedata.cpp..gameloop.cpp · Relevance: data
- Status: specified
- Signature: `__fastcall`, ECX = file name, EDX = descriptor out, stack `[palette, file, line]` (file/line unused), `ret 0xc`.
- Behavior: `SBmpAllocLoadImage(name, palette, &pixels, &width, &height, 0, 0, 0x444810)`. Failure → fatal error `0x4ceb90(name, SErrGetLastError())`. - Callers/callees: 21 sites (dialog and UI images). Prior evidence: [dialog bin](../native-dialog-bin.md).

### 0x00444cc0 `PollTurn` — network-turn gate for one frame
- Module: gamedata.cpp..gameloop.cpp · Relevance: simulation
- Status: specified
- Signature: `__fastcall`, ECX = DWORD out "turn boundary redrawn"; returns 1 = the frame may run, 0 = waiting.
- Behavior:
  1. `*out = 0`; `--0x6663fc`. A nonzero result returns 1 without polling.
  2. Otherwise it calls the turn manager `0x476c00`. Not ready: `0x6663fc = 1` (poll again next call); if `0x666400` = 0, set it to 1 and record `0x66642c = GetTickCount()`; return 0.
  3. Ready: if `0x666400` was set, `0x66642c = now − 0x66642c`. If that is < 100 (unsigned), `0x6663f8 += speedMs/2`. Otherwise `0x6663f8 = now + (speedMs * framesPerTurn) >> 1`, using unsigned multiply/shift with `speedMs = 0x503360[0x6d3130]` and `framesPerTurn = 0x666404[0x6d3130]`.
  4. `0x666400 = 0`, `0x6663fc = 0x666404[speed]`. In multiplayer (`0x672664`): `*out = 1`, then `0x417610` (`0x5c59d0 = 1`), minimap refresh `0x46e0e0` and `0x47a2f0`. Return 1.
- Notes: Single player has 1 frame per turn (`0x445110`), so the turn manager is polled every frame.
- Callers/callees: `0x444e30`.

### 0x00444e30 `RunPendingFrames` — the per-tick frame sequence
- Module: gamedata.cpp..gameloop.cpp · Relevance: simulation
- Status: specified
- Signature: `__fastcall`, ECX = force-stop flag (0 from `0x4451f0`); returns 1 when at least one unpaused object step ran.
- Behavior: `deadline = now + 2000`, `steps = 0`, `0x6663f0 = 0`. It repeats at most `0x50335c` times:
  1. Replay: `0x4769b0` (feed replay commands).
  2. `0x444cc0(&drew)` = 0 → reason 1, exit.
  3. Replay and (`0x67cc7c` ≠ 0 or ECX ≠ 0) → `0x480fb0` (replay clock display), reason 2, exit.
  4. `0x6663ed` = 0 → reason 4, exit.
  5. Only when the application is active (`0x66fd24`) or in multiplayer: set flag bit 1 of layer 5 (`0x6d0bf5 |= 2`). If paused (`0x67517c` via `0x47cb60`), run `0x444de0`. Otherwise `++0x52651c`, set the result to 1, `++steps` and run the object step `0x445070`. Then `0x4781c0(1)` (RNG on), triggers `0x4be500(ECX = 0x503360[speed])`, `0x4781c0(0)`; in a replay, `0x480fb0`. An inactive single-player window skips step 5 entirely: no frame, no triggers.
  6. `0x6663f8 += 0x503360[speed]`. If `now − 0x6663f8 < 0` (signed) → reason 5, exit. If `deadline − now < 0` → reason 6, exit. If `drew` ≠ 0 and (not replay or `0x6663e8` = 0) → reason 7, exit. `0x6663e8` has no writer, so this reduces to `drew` ≠ 0.
  Exiting by count leaves reason 0. On every exit `0x666424 = steps`.
- Callers/callees: `0x4451f0`. Prior evidence: [frame order](../native-frame.md) (object step, trigger order, speed table).

### 0x004451f0 `GameLoop` — inner loop until the game stops
- Module: gameloop.cpp · Relevance: simulation
- Status: specified
- Signature: no arguments.
- Behavior: `0x6663fc = 1`, `0x666400 = 0`, `0x6663f8 = now`, `redraw = 0`. While `0x6663ed` ≠ 0:
  1. `PumpWindowMessages(3)` (`0x4401c0`); `now = GetTickCount()`.
  2. When not waiting for a turn and `|0x6663f8 − now|` (signed) > `0x50337c[speed]`, set `0x6663f8 = now` (drop the backlog).
  3. Cursor update `0x43ea40`.
  4. If `0x6663f4 + now > 10` (unsigned): `0x6663f4 = −now`, scroll step `0x49bf10`, redraw = 1.
  5. `0x476b80` (dispatch received network packets), `0x4be950` (empty), `0x470150` (Battle.net `/league`/`/stats` timer).
  6. If `now − 0x6663f8 ≥ 0` (signed): `0x444e30(0)`, redraw = 1.
  7. `0x445020`.
  8. If `0x665e3c` ≠ 0 or redraw: clear both and present the frame (`0x4c5360`).
- Callers/callees: `0x445310`.
