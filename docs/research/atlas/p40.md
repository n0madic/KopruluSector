# P40: Trigger action and condition handlers, player-selector aggregators, unit-count caches and the leaderboard

This package is the trigger object that follows `title.cpp` (no assertion name survives; the atlas bracket is `title.cpp..uimulti.cpp`). Apart from the two title-screen helpers at its start, it holds every handler of the normal TRIG action table `0x50df68` (60 entries) and condition table `0x50e058` (24 entries), the helpers those handlers share, and the leaderboard ranking used by the console leaderboard. The scheduler, list runner, condition evaluator and action runner that call these handlers (`0x4be500`, `0x4bdfd0`, `0x4bded0`, `0x4bdf10`) belong to the next package and are described in [native-triggers.md](../native-triggers.md).

Most of the behavior was already established by executed probes. The atlas links them and adds what they lack:

- [Triggers, waits, clocks](../native-triggers.md): scheduler, Wait, Preserve, switches, timers, Set Next Scenario.
- [Scalar counters and selectors](../native-trigger-counters.md): resources, scores, deaths, kills, the selector aggregators.
- [Rankings and Opponents](../native-trigger-ranking.md).
- [Command/Bring and count caches](../native-trigger-unit-counts.md).
- [Unit actions, alliances, outcomes](../native-trigger-unit-actions.md): Kill/Remove, Create, Order, Give, Victory/Defeat/Draw, Set Alliance.
- [Give ownership](../native-trigger-ownership.md), [Move Unit](../native-trigger-move.md), [grounded Move](../native-trigger-grounded-move.md).

## Shared conventions

**Calling convention.** The action runner calls `table[type]` with `ECX` = the raw 32-byte action; the condition evaluator calls with `ECX` = the raw 20-byte condition. Both test the return in `EAX`: a condition returns nonzero for true; an action returns 1 to advance and 0 to suspend the trigger at this action (it is re-entered on the next trigger visit).

**Raw action (32 bytes):** `+0x00` u32 location (one-based; handlers use only its low byte unless stated), `+0x04` u32 string ID, `+0x08` u32 WAV string ID, `+0x0c` u32 time (ms), `+0x10` u32 player selector, `+0x14` u32 second value (amount, destination location, destination player, percent, switch, AI script ID, property index), `+0x18` u16 unit type (also the alliance status and the leaderboard type operand), `+0x1a` u8 action type, `+0x1b` u8 modifier/quantity, `+0x1c` u8 flags (bit `0x01` "wait in progress", `0x02` ignored, `0x04` always display text).

**Raw condition (20 bytes):** `+0x00` u32 location, `+0x04` u32 player selector, `+0x08` u32 amount, `+0x0c` u16 unit type, `+0x0e` u8 comparison (0 at least, 1 at most, 10 exactly; any other value is false), `+0x0f` u8 type, `+0x10` u8 resource/score type or switch index, `+0x11` u8 flags. All comparisons are unsigned 32-bit.

**Locations (MRGN).** Record `n` (one-based, 1…255) is at `0x534f40 + 20·(n−1)` (equivalently `0x534f2c + 20·n`): `+0x00/+0x04/+0x08/+0x0c` s32 left/top/right/bottom, `+0x10` u16 string, `+0x12` u16 elevation flags. A location *center* is always `(left+right)/2`, `(top+bottom)/2` in signed 32-bit arithmetic truncated toward zero. Spatial queries receive the four corners narrowed to u16. Every location-taking handler first requires the low byte nonzero (the `cmp al,0xff; ja` that follows is never taken).

**Elevation filter** `0x4b95f0` excludes a unit when the location's flag bit for its height and layer is set: ground height 0/1/2 → bits 1/2/4, air (status `0x4` at `+0xdc`) height 0/1/2 → bits 8/0x10/0x20 (height from `GetTerrainHeightAt` `0x445690` at the sprite position).

**Player selectors.** Every scalar or per-player function decodes its selector the same way (the jump tables at `0x4b6b90`, `0x4b6cb8`, `0x4b6e38`, `0x4b6fa0`, `0x4b7130`, `0x4b7f80`, `0x4b83a8`, `0x4b8588`, `0x4b87c8`, `0x4b8914`, `0x4b8be8`, `0x4b8dc0`, `0x4b9abc`, `0x4b9e0c`, `0x4ba228`, `0x4ba310`, `0x4ba4cc`, `0x4ba624`, `0x4ba7d0`, 14 entries each for selectors 13…26, were all resolved and have this shape):

| Selector | Meaning | Handling |
|---|---|---|
| 0–11 and anything outside 13–26 | direct slot | used as is (setters reject ≥ 8) |
| 13 | Current Player | `0x4bda70()` = `0x6ca754`, then direct |
| 14 | Foes | aggregator `0x4b9b10` (limited `0x4b9b80`) |
| 15 | Allies | `0x4b9730` (`0x4b97a0`) |
| 16 | Neutral Players | `0x4b9f70` (`0x4b9fe0`) |
| 17 | All Players | `0x4b9660` (`0x4b96c0`) |
| 18–21 | Force 1–4 | `0x4b9c60` (`0x4b9cc0`) |
| 22–25 | unused | returns 0 |
| 26 | Non-Allied Victory Players | `0x4b9e60` (`0x4b9ee0`) |

An aggregator walks the eligible-player iterator `0x4b3160`/`0x4b3170` (ascending slots 0–7 of controller 1/2/3/4/7 not yet finished, or the four-entry alternate sequence `0x5264ac`, see [counters](../native-trigger-counters.md#player-selectors)), calls the same function again with `ECX` = slot, `EDX` = the same type and the same stack argument (the getters `GetDeaths`, `GetKills`, `GetResources`, `GetScore` and `CountOpponents` pass 0 instead), and returns the 32-bit wrapping sum. Set Alliance `0x4b6e90` alone uses a different table shape (Current and 22–25 are no-ops, see its entry).

**Unit-type groups.** Unit type 229 = Any Unit, 230 = Men, 231 = Buildings, 232 = Factories. Unit predicates test the `units.dat` group byte `0x523c40[type]` bits `0x08`/`0x10`/`0x20`; every other value must equal the unit type `+0x64` exactly. Count getters use the aggregate arrays instead (Any = Men + Buildings).

**Unit fields used** (1.16.1 BWAPI layout, confirmed here): `+0x0c` sprite (sprite `+0x0f` selection timer, `+0x14/+0x16` s16 position), `+0x4c` owner, `+0x4d` order, `+0x60` shields (×256), `+0x64` type, `+0x6c` next unit of the owner, `+0xa2` energy (×256), `+0xb0` cargo slots (u16 each), `+0xc0` carried powerup (workers) / first hangar child, `+0xc8` hangar inside count, `+0xd0` resource amount / Nydus exit, `+0xd4` silo nuke / carrying worker of a powerup, `+0xdc` status (`0x1` completed, `0x2` grounded building, `0x4` in air, `0x10` burrowed, `0x20000` mobility bit ([V01 item 1](v01.md)), `0x4000000` invincible, `0x40000000` hallucination), `+0x110` remove timer, `+0x134` AI record. `units.dat`: `0x521660` special flags (`0x1` building, `0x2` addon, `0x8` worker, `0x10` subunit, `0x800` single entity/powerup, `0x2000` resource container, `0x20000` requires creep, `0x200000` spellcaster, `0x20000000` invincible), `0x520708` max HP (×256), `0x520458` shields enabled, `0x520540` max shields, `0x523fe0` cargo capacity.

**Trigger-wide globals.** Current player `0x6ca754` (`0x4bda70`); current trigger node `0x6ca790`, its execution flags at node `+0x948` (`0x01` executing, `0x04` preserve, `0x08` disabled, `0x10` cinematic skipped, `0x20` paused by this trigger, `0x40` skipping forbidden); trigger pause byte `0x6ca740`; per-player wait `0x6ca760[8]` (active) and `0x6ca768[8]` (remaining ms, `0xffffffff` = indefinite); helpers `0x4bd560` = flag `0x10` of the current trigger ("skipping"), `0x4bd580(p)` = wait active, `0x4bda60(p, ms)` = start wait. Flag `0x10` is set only by the local Escape-skip `0x4bda80` (single player, mission key `0x526524` < 32, which includes custom maps with key 0; only the local player's executing triggers without flag `0x40`), which also clears the local wait, forces a trigger check (`0x6ca748 = 1`) and calls `StopAllStreamedSounds` `0x49db50`, `CancelTriggerPortrait` `0x4a73e0` and `ClearTriggerTextLines` `0x46aef0`. Local player `0x508d50`; multiplayer byte `0x672664`; replay flag `0x67cc90`; controller byte `0x6726d0 + 36·slot`; alliance matrix `0x534914 + 12·from + to`.

**Unit-count cache.** Key byte `0x6ca6d0` (0 invalid, 1 global, 2 location) and location byte `0x6ca6d1`; arrays: all-unit individual `0x6c7c10`, completed individual `0x6c5150` (`4·(12·type + player)`), aggregate block `0x6c4c10` (`0x540` bytes): Men all/completed `0x6c4c10`/`0x6c4c40`, Buildings `0x6c4d60`/`0x6c4d90`, Factories `0x6c4eb0`/`0x6c4ee0`.

**Kill/Remove/Move globals.** `0x6c4c00` remove mode (0 kill, 1 remove), `0x6c4c04` per-player location quantity, `0x6c4c08` "inside a recursive child" flag, `0x6c4c0c` Move quantity.

**Leaderboard globals.** `0x5349ec` u8 leaderboard action type, `0x5349ed` u8 location (zero-based), `0x5349ee` u16 unit/resource/score type, `0x5349f0` u32 goal, `0x5349f4` u32 label string, `0x5349e8` u32 include computer players (initialized to 1 by `0x4be240`), entries `0x6ca6d8[8]` = `{s32 player (−1 empty), u32 value}`, refresh divider `0x6ca750` (u16, post-decremented by `0x4be410`; an old value of 0 reloads 15 and runs `0x4ba910`).

**Other trigger state written here.** Switches `0x534f20[8]` (u32 bitsets), countdown `0x5349d4`, countdown-paused `0x53632c`, elapsed seconds `0x5349d8`, mission objectives `0x5349a4[8]`, pending results `0x6ca758[8]`, result-UI delay `0x6ca74c`, next-scenario string `0x526526`, unit-property table `0x6c4700[64]` (20-byte UPRP records).

### 0x004b55d0 `TitleBlinkTimer` — 500 ms title-screen image toggle
- Module: title.cpp (registered by `0x4b5300` through `0x4c5960(500, 0x4b55d0)`) · Relevance: ui

### 0x004b56f0 `TrigActMoveLocation` — action 38
- Module: title.cpp..uimulti.cpp · Relevance: script
- Status: specified
- Signature: `__fastcall`, ECX = action; returns 1.
- Behavior:
  1. Requires source low byte `+0x00` ≠ 0 and destination dword `+0x14` in 1…255; otherwise returns 1 without effect.
  2. `p = GetTriggerUnitOrLocationCenter` `0x4b7330`(location = source−1, EDX = player selector `+0x10`, CX = unit type `+0x18`): the sprite position of the first unit at the source location matching selector and type (source elevation flags apply; cargo and carried powerups count, see `0x4b71f0`), else the source center.
  3. With `L` = destination record `0x534f2c + 20·dest`: `dx = p.x − (L.left+L.right)/2`, `L.right += dx`, `L.left += dx`; `dy = p.y − (L.top+L.bottom)/2`, `L.top += dy`, `L.bottom += dy` (signed, halves truncated toward zero).
  4. Clamp, in this order: if `left < 0`: `right −= left`, `left = 0`; if `top < 0`: `bottom −= top`, `top = 0`; with `W` = map width `0x543230` and `H` = height `0x543234` (u16 pixels): if `right ≥ W`: `left += W − right − 1`, `right = W − 1`; if `bottom ≥ H`: `top += H − bottom − 1`, `bottom = H − 1`. Comparisons are signed. A location wider than the map can end with a negative left; nothing re-clamps it.
  5. `InvalidateUnitCountCache` `0x4b9820`.
- Prior evidence: invalidation anchor in [unit counts](../native-trigger-unit-counts.md#cache-layout-and-global-copy).
