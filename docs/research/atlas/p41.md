# P41: Lobby slot actions, campaign progression, unit selection and targeting, the trigger engine, end-of-game dialogs and video options

This package covers `0x4bad10`–`0x4bec30` (120 functions). It spans the end of `uiMulti.cpp`, all of `uiSingle.cpp` and the objects between it and `victory.cpp`, `victory.cpp` itself, and the start of the following engine run (`victory.cpp..creep.cpp`). Its pieces are:

1. **Multiplayer lobby wrappers** (`0x4bad10`–`0x4bb340`, except `0x4baf70`). Chat-room slot, race, team and start actions and the Battle.net join step. They are `excluded`. `0x4baf70` (delete a character and its saved games) is single-player profile UI.
2. **Single-player game creation and campaign progression** (`0x4bb360`–`0x4bbc20`). Local slot placement, creation of a campaign mission or of the next scenario of a custom game, the campaign tables at `0x50e0b8`/`0x50e0c4`, the "next mission" dispatcher after the score screen, the SetNextScenario resolver, the mission-warp cheat parser and the profile progress fields.
3. **Technology/upgrade recipe iterators** used by Give Unit (`0x4bbcb0`, `0x4bbd40`).
4. **In-game unit selection** (`0x4bbdd0`–`0x4bce70`): drag box, click and type selection, shift add/remove, the pick-under-cursor routine and the selection filter.
5. **Targeted-order confirmation** (`0x4bc820`, `0x4bceb0`): what happens when the player clicks a target while a targeting order is pending.
6. **Victory/defeat dialogs** (`0x4bcf30`–`0x4bd400`) and the Battle.net report gate.
7. **Trigger engine** (`0x4bd460`–`0x4be500`): flag setters, pending/committed results, save/load of trigger lists, owner expansion, condition evaluator, action runner, list runner, result resolver, the two clocks and the scheduler.
8. **Video options dialog** (`0x4be5f0`–`0x4be8d0`): gamma slider, color cycling, portrait mode and their registry persistence.
9. **Library code**: an empty function, eight import thunks, zlib CRC-32 and SHA-1.

## Data model

**Player slots** `0x6726d0 + 36·s` (s = 0…7): `+0` u8 controller (1 computer, 2 human, 5 lobby computer, 6 open, 8 closed, 10 defeated human, 11 defeated computer), `+1` u8 race (0 Zerg, 1 Terran, 2 Protoss), `+2` u8 force (one-based), `+3` 25-byte name; the DWORD at `+(−4)` is the Storm ID. Local slot `0x508d50` (also copied to `0x508d54`). The player name typed in the glue is `0x672690`.

**Campaign tables.** `0x50e0b8` holds three pointers (Zerg `0x4f0700`, Terran `0x4f0680`, Protoss `0x4f0778`) and `0x50e0c4` the expansion three (Zerg `0x4f0848`, Terran `0x4f07f0`, Protoss `0x4f08d8`). A row is 8 bytes: u16 label (gluAll/history string, 0 = not listed), u16 mission index (`arr\mapdata.dat` index, also the `0x51abb8` directory string index; 0 terminates the table), u16 cinematic ID (0 = a playable mission), u8 race, u8 hidden (1 = selectable only through SetNextScenario or a letter suffix). [Native triggers](../native-triggers.md#actual-campaign-ordering-and-hidden-variants) lists the row counts. The terminator rows carry the campaign race: Terran 1, Zerg 0, Protoss 2, expansion Terran 1, expansion Zerg 0, expansion Protoss 2. Cached current row `0x6ca718`; current mission index u16 `0x526524`; pending next-scenario file name `0x526526` (empty = none); pending cinematic `0x50e0d0` (initial 28); "custom single-player game" mode `0x6ca71c` (with its saved copy byte `0x5264c3`); expansion byte `0x536720`; game mode word `0x6662b8` (3 game, 4 glue, 5 restart mission, 9 epilog, 10 cinematic); glue state `0x66a274` (6 campaign menu, 7/8/9 Terran/Zerg/Protoss ready room, 22 expansion campaign menu).

**Profile progress.** A character record is `0x70` bytes ([P03](p03.md) `0x40d680`/`0x40d830`). The highest reached mission index is a u32 per race at `+0x28 + 4·race` (original) and `+0x34 + 4·race` (expansion).

**Selection.** The 12-entry local selection is `0x6a6070`; the console snapshot of it is `0x6ab4c8` (12 entries) with the status unit `0x6ab4c4`. The drag box is `0x6ca720` (u8 active), anchor `0x6ca724`/`0x6ca726` (s16 x, y of the button press, screen coordinates), rectangle `0x6ca728`/`0x6ca72a`/`0x6ca72c`/`0x6ca72e` (s16 left, top, right, bottom; screen coordinates while dragging, map coordinates after release), and `0x6ca730` (u32: the press was a double click). Keys: Shift `0x665e68`, Ctrl `0x665e69`, Alt `0x665e6a`. Local vision mask `0x672668`; replay vision `0x67cc84`, replay "show all" `0x67cc88`, replay flag `0x67cc90`. Screen origin `0x543218`/`0x54321c`, map pixel height u16 `0x543234`.

**Unselectable types** (`0x4bc730`, jump table `0x4bc754` = {return 1 `0x4bc74b`, return 0 `0x4bc751`} indexed by byte map `0x4bc75c`[type − 14], 195 entries): 14 Nuclear Missile, 85 Scarab, 105 Disruption Web, 202 Dark Swarm, 205 Upper Level Door, 206 Right Upper Level Door, 207 Pit Door, 208 Right Pit Door. Every other type (and every type outside 14…208) returns 0.

**Trigger lists.** `0x50e0d8 + 12·p` (p = 0…7) are Storm intrusive list headers: `+4` tail link, `+8` head node (a value ≤ 0 means empty). A node is `0x968` bytes: `+0` back link, `+4` next node (≤ 0 ends), `+8` the 2400-byte raw TRIG record. Native offsets: conditions from `+8` (20 bytes each, type `+0x17`, flags `+0x19`), actions from `+0x148` (32 bytes each, type `+0x162`, flags `+0x164`), owner bytes `+0x94c…+0x966` (raw `+0x944`), execution flags u32 `+0x948`, continuation byte `+0x967`. Execution flags (BWAPI names): `0x01` executing, `0x02` ignore defeat, `0x04` preserve, `0x08` disabled, `0x10` cinematic skipped, `0x20` paused the game, `0x40` skipping forbidden. Trigger globals: current player u32 `0x6ca754`, current node `0x6ca790`, cycle countdown u16 `0x6ca748`, time divider u16 `0x6ca744`, leaderboard divider u16 `0x6ca750`, result-UI delay u16 `0x6ca74c`, trigger pause byte `0x6ca740`, waits `0x6ca760[8]` (active bytes) and `0x6ca768[8]` (u32 remaining ms), pending results `0x6ca758[8]`, committed results `0x5349e0[8]` (0 none, 1 dropped, 2 defeated, 3 victory, 4 ignore-defeat, 5 draw), initial participants `0x6ca788[8]`, elapsed seconds `0x5349d8`, countdown seconds `0x5349d4`, countdown paused `0x53632c`, switches `0x534f20[8]`, UPRP table `0x6c4700` (`0x500` bytes). End-dialog flags: `0x6ca73c` dialog open, `0x6ca734` dialog dismissed, `0x6ca738` Battle.net result reported.

**Trigger dispatch tables** (resolved; semantics in [P40](p40.md#action-and-condition-tables)). Condition table `0x50e058` (24 entries): 0 `0x4b8e70`, 1 `0x4b8e90`, 2 `0x4b8ed0`, 3 `0x4b8f20`, 4 `0x4b8f80`, 5 `0x4b8fd0`, 6 `0x4b9070`, 7 `0x4b90e0`, 8 `0x4b9160`, 9 `0x4b91c0`, 10 `0x4b9220`, 11 `0x4b9280`, 12 `0x4b92e0`, 13 `0x4b8e80`, 14 `0x4b9320`, 15 `0x4b9360`, 16 `0x4b93b0`, 17 `0x4b9420`, 18 `0x4b94a0`, 19 `0x4b9510`, 20 `0x4b9580`, 21 `0x4b9020`, 22 `0x4b8e70`, 23 `0x4b8e80`. Action table `0x50df68` (60 entries) exactly as tabulated in P40; entry 6 (`0x50df80` = `0x4b6080` UnpauseGame) is also called directly by the action runner. Owner-expansion jump table `0x4bddb8` = {`0x4bdd92` skip, `0x4bdc24` all players, `0x4bdb50` force}, indexed by byte map `0x4bddc4`[owner − 13] (14 entries): owners 13–16 → 0, 17 → 1, 18–21 → 2, 22–26 → 0. Owners 0–12 take the direct-slot path.

**Recipe tables.** Technology rows at `0x4f0940`…`0x4f0a48` (12 bytes: u16 unit type, up to five u16 tech IDs, ended by 44): Marine 0→{0}; Firebat 32→{0}; Science Vessel 9→{6, 7, 2}; Ghost 1→{1, 10}; Vulture 2→{3}; Siege Tank 5→{5}; Siege Tank (siege) 30→{5}; Wraith 8→{9}; Battlecruiser 12→{8}; Queen 45→{12, 18, 13, 17}; Zergling 37, Hydralisk 38, Drone 41, Infested Terran 50→{11}; Defiler 46→{11, 14, 15, 16}; High Templar 67→{23, 19, 20}; Arbiter 71→{21, 22}; Medic 34→{34, 24, 30}; Corsair 60→{25}; Dark Templar 61→{28}; Dark Archon 63→{27, 29, 31}; Lurker 103→{32}; Hydralisk 38→{32}. Upgrade rows at `0x4f0a58`…`0x4f0b48` (10 bytes: u16 type, up to four u16 upgrade IDs, ended by 61): Marine 0→{16}; Vulture 2→{17}; Science Vessel 9→{19}; Ghost 1→{20, 21}; Wraith 8→{22}; Battlecruiser 12→{23}; Overlord 42→{24, 25, 26}; Zergling 37→{27, 28}; Hydralisk 38→{29, 30}; Queen 45→{31}; Defiler 46→{32}; Dragoon 66→{33}; Zealot 65→{34}; Reaver 83→{35, 36}; Shuttle 69→{37}; Observer 84→{38, 39}; High Templar 67→{40}; Scout 70→{41, 42}; Carrier 72→{43}; Arbiter 71→{44}; Goliath 3→{54}; Ultralisk 39→{53, 52}; Medic 34→{51}; Dark Archon 63→{49}; Corsair 60→{47}. Both iterators walk the rows from the **last to the first**.

**Video options.** Gamma u32 `0x50f2ec` (60…140, default 100; `0x4cf930` stores a value, mapping anything outside 60…140 to 100; `0x4cf870` reads it; `0x4ccf20` rebuilds the palette), color cycling u32 `0x50e138` (initial 1), portrait mode `0x50d7c8` (`0x4a6a30`/`0x4a6e90`). Interact table `0x50e13c` (5 entries, control IDs 1–5): 1 `0x4be8d0` gamma slider, 2 `0x4be5f0` color cycling, 3–5 `0x4be820` portrait mode 0/1/2. Saved values while the dialog is open: `0x6ca794` color cycling, `0x6ca798` gamma, `0x6ca79c` portrait mode.

**Code without atlas entries in this range** (embedded after a `ret`): `0x4be3a0` releases the local player's trigger wait (`0x6ca760[local]` = 0, `0x6ca768[local]` = 0, cycle `0x6ca748` = 1; see [P40](p40.md)); `0x4be5c0` opens the video options (`0x6ca794` = `0x50e138`, `0x6ca798` = gamma, `0x6ca79c` = portrait mode, then `OpenModelessDialog`(`rez\video.bin`, `0x4be6a0`)); `0x4be880` is the exit callback registered by `0x4be790` (CL = 0 → `SRegSaveValue("Starcraft", "Gamma"/"ColorCycle"/"UnitPortraits", 0, value)` with the current gamma (`0x4cf870`), `0x50e138` and the portrait mode read through `0x4a6a30`; CL ≠ 0 → nothing). It lies in the padding after `0x4be820`'s `ret`, so the caller index attributes its `0x4a6a30` call (`0x4be8b2`) to `0x4be820`).
