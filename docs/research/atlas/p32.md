# P32: Unit path construction, local path search and the AI script engine

This package covers `0x491210`–`0x495bb0` (51 functions). It spans the end of the path-construction object (`sai_pathcreate.cpp..sai_scripts.cpp`), `sai_scripts.cpp` itself and the start of the object before `saveload.cpp`. The functions form six groups.

1. **Path construction** (`0x491210`–`0x493200`). A unit's path request is a 0x170-byte stack context (layout below), filled by `AdvancePathWaypoint` `0x48ec50`. `0x491210` (new path) or `0x4919b0` (next segment of an existing route) resolves the regions and unit extents, gets a region route from the long search `0x491300` ([region paths](../native-region-paths.md)), and calls `0x491c10`. That function picks the local target for the current route position, handles target units and goal snapping, then runs the local geometric A* search `0x491f50`. The search expands nodes through `0x491ba0` and the P30 neighbor generators, filters neighbors by the visited-area slab structure (`0x492de0`, `0x4930b0`, `0x493200`), and writes up to 50 points through `0x492860`.
2. **Heaps.** Two binary min-heaps of node pointers. The region heap at `0x69b588` is used by `0x491300` (priority at node `+0x14`). The local heap at `0x69d6c8` is used by `0x491f50` (priority at node `+0x1c`).
3. **AI script engine** (`0x493240`–`0x494f80`). These are the script pool, the BIN loader, the launch gate, the scheduler, the opcode interpreter `0x493a60` with its 113-entry dispatch table, save/load of the pool, and the town-spawning helpers.
4. **AI building placement** (`0x494fc0`, `0x495480`, `0x495bb0`), covered by [AI placement](../native-ai-placement.md).
5. **Resource areas** (`0x495440`–`0x495890`): save/load of the area table and the clustering helpers of the generator `0x497a20`, covered by [resource generation](../native-resource-generation.md).
6. **Leaves**: `0x4928f0`, an always-false placement check.

## Data model

**Path context** (0x170 bytes, on the stack of `0x48ec50`):

| Offset | Meaning |
|---|---|
| `+0x00` | unit |
| `+0x04/+0x06` | source x, y (signed WORDs) |
| `+0x08/+0x0a` | requested destination x, y |
| `+0x0c` | target unit for the current segment, or 0 |
| `+0x10..+0x16` | target box left, top, right, bottom (WORDs; `0x83008300` per DWORD = none) |
| `+0x18` | goal point (packed DWORD; starts as `+0x08`, may be replaced) |
| `+0x1c` | long-search partial byte |
| `+0x1d` | local search ended in the fallback tally |
| `+0x1e` | local search reached its goal (byte) |
| `+0x1f` | goal was moved to a substitute point or is unreachable (byte); `0x48ec50` copies it into CUnit status bit `0x80000` |
| `+0x20` | route: up to 50 region WORDs |
| `+0x84` | route cursor (signed WORD; 0xffff before the first segment) |
| `+0x86` | route length (WORD, ≤ 50) |
| `+0x88` | local points: up to 50 packed DWORDs |
| `+0x150/+0x152` | current point index / point count (WORDs) |
| `+0x154` | low byte of the full region-chain length |
| `+0x158..+0x15e` | unit extents −left, −up, right, down (units.dat dimensions `0x522c38 + 8·type`) |
| `+0x160/+0x162` | source / destination region IDs |
| `+0x164/+0x168` | long-search node count / peak open count (WORDs) |
| `+0x166/+0x16a` | local-search node count / peak open count (WORDs) |

**Local search nodes** (32 bytes, arena `0x69b788`, 250 nodes up to `0x69d6c8`). Node 0 is the start node.

| Offset | Meaning |
|---|---|
| `+0x00` | position (x WORD, y WORD) |
| `+0x04` | region ID (WORD) |
| `+0x06` | in-near byte: the region is marked as a neighbor of the anchor region |
| `+0x07` | in-target byte: the region equals the next route region |
| `+0x08` | is-goal byte |
| `+0x09` | closed byte |
| `+0x0a` | direction flags byte (expansion mask passed to `0x488320`) |
| `+0x0b` | depth byte (parent depth + 1) |
| `+0x10` | parent node |
| `+0x14` | heuristic h = ApproxDistance(position·256, target·256) |
| `+0x18` | cost g |
| `+0x1c` | priority f = g + h |

The local heap is at `0x69d6c8`: slot 0 holds the sentinel, slots 1…150 hold entries, the count is at `0x69d924` and the sentinel pointer at `0x69d928` (heap `+0x25c/+0x260`). The sentinel is a stack object whose priority is −1.

**Visited-area slabs** (reset by `0x493200`). The visited rectangles are kept as vertical slabs: boundary array `xs` at `0x69ec08`, slab count at `0x69ee0c` (at most 128), and a slab → list index array at `0x69ee10`. The lists are at `0x69f018 + 0x54·k`; each holds a DWORD count followed by up to 10 sorted, disjoint inclusive y-intervals {lo, hi} (DWORDs). Slab s covers `xs[s] ≤ x < xs[s+1]`. List k is allocated when the slab count was k, so 128 lists end exactly at `0x6a1a18`.

**Region-heap search** (`0x491300`): stack arena of 350 nodes of 24 bytes; heap entries at `0x69b588` (slot 0 = sentinel copy), count `0x69b780`, sentinel pointer `0x69b784`; region record `+8` holds the temporary node back-reference. See [region paths](../native-region-paths.md). The local search reuses region `+8` as a counter (below).

**AI scripts.** The pool is at `0x6a1a18` (100 slots × 0x34 bytes, free head at pool `+0x1450`). The descriptor `0x6a2e6c` holds the pool pointer and the active head `0x6a2e70`. Script layout: `+0` next, `+4` prev, `+8` PC, `+0xc` wait, `+0x10` player, `+0x14..+0x20` rectangle (signed DWORDs left, top, right, bottom), `+0x24/+0x28` centre, `+0x2c` town, `+0x30` flags (bit 0 = BWScript, bit 1 = killable, bit 2 = kill pending, bits 3+ = resource-area index for area towns). The BIN buffers are `0x6a2e74` (aiscript.bin) and `0x6a2e78` (bwscript.bin). The shared return PC is `0x6a2e7c`. The builder override for placement is `0x6a2e80`. The defense-anchor count is `0x6a2e84` and the anchor region WORDs are at `0x6a5d70`.

**Resource areas.** The table is at `0x6a2e88`, 250 records of 0x30 bytes, with index 0 unused. Fields: `+0/+2` x/y (signed WORD), `+4/+5` mineral/gas counts, `+6` start marker, `+7` flags (bit 0 occupied, bit 1 reserved), `+8/+0xc` mineral/gas sums. The used count is at `0x6a5d68` and the refresh countdown at `0x6a5d6c` ([resource areas](../native-resource-areas.md)).

### 0x00491300 `SearchRegionPath` — long A* over the region graph
- Module: sai_pathcreate.cpp..sai_scripts.cpp · Relevance: simulation
- Status: covered
- Signature: `__fastcall`, ECX = path context (reads `+4..+0xa`, `+0x160/+0x162`); returns 1 when the stored route has ≥ 1 region.
- Behavior: [Region paths](../native-region-paths.md) specifies it completely. In short: equal region IDs return 0 before any write. Ground-neighbor prefix in the source group, full list otherwise. Edge cost and heuristic come from `ApproxDistance` on fixed-8 points; regions outside the source group cost ×2 (`(d·512)/256`, signed). The heap moves parents on equal priority. The search stops at 125 open nodes or 350 arena nodes with the partial byte left 0; an empty open set gives partial byte 1 and the visited node with the smallest heuristic. Differing groups run target → source first. The output is the source-side prefix of ≤ 50 regions, with byte `+0x154` = low 8 bits of the full chain length and cursor = 0xffff. The `+8` back-references are cleared at the end. It uses the region heap at `0x69b588` (`0x491a70`, `0x491b20`) and a 0x2124-byte stack arena (`_alloca_probe`).
- Callers/callees: `0x40e4e0`, `0x48e690`, `0x48e9b0`, `0x491210`, `0x495e70`, `0x496780`, `0x496930`, `0x496ac0`, `0x4976d0`.
- Prior evidence: [region paths](../native-region-paths.md), [campaign regions](../native-campaign-regions.md), [AI placement](../native-ai-placement.md), [workers](../native-workers.md).

### 0x00491a70 `RegionHeapChangePriority` — change a node's priority in the region heap
- Module: sai_pathcreate.cpp..sai_scripts.cpp · Relevance: simulation
- Status: covered
- Signature: `__thiscall`, ECX = heap (`0x69b588`), stack [node, new priority]; `ret 8`.
- Behavior: Same algorithm as `0x492900` with the priority at node `+0x14`, count at heap `+0x1f8` and sentinel at `+0x1fc`. Equal priority returns at once. ### 0x00491c10 `BuildLocalPathSegment` — choose the segment target and run the local search
- Module: sai_pathcreate.cpp..sai_scripts.cpp · Relevance: simulation
- Status: specified
- Signature: `__fastcall`, ECX = path context; returns 0, 1, or the result of `0x491f50`.
- Behavior:
  1. Cursor `+0x84` += 1 (16-bit). If cursor ≥ length `+0x86` (signed), return 0. If route[cursor] ≠ source region `+0x160`, scan forward for it. If it is not found, return 0; otherwise the cursor = the found index.
  2. remaining = length − cursor. If remaining ≤ 3, the local target T = goal `+0x18`, and `final` = `checkTarget` = 1. Otherwise T = centre of route[cursor + 2] (`GetRegionCenterPoint` `0x481a60`), and both flags = 0.
  3. If cursor = length − 1: when the source region ≠ destination region `+0x162`, it calls `0x492a90`(ECX = context, EDX = source region), which moves the goal into the source region and always returns 1. In both cases next = 0x1ffe (no next region). A zero return would call `FatalError` `0x4cc190("error in GetClosestReachable")`; that branch is unreachable. Otherwise next = route[cursor + 1].
  4. `+0x0c` = 0. If `checkTarget`:
     - The target unit is the unit's move-target unit (CUnit `+0x14`). If that is 0, it scans `FindUnitsAtPoint` `0x421c80`(ECX = unit, goal x, goal y) in list order and takes the first candidate with `IsPathObstacleUnit` `0x42e490`(ECX = candidate, EDX = unit) ≠ 0, then releases the query (`0x4222b0`). A beacon target (`IsBeaconType` `0x421620`) is dropped.
     - **No target unit:** the box DWORDs `+0x10/+0x14` = `0x83008300`. Copy P = T and call `0x492c00`(ECX = context, EDX = &P). If it returns nonzero and P ≠ T, then T = P and goal `+0x18` = P.
     - **Target unit:** the box is the target's sprite position minus its dimensions, grown by the searching unit's dimensions plus 1 (16-bit). That is left = tx − tL − uR − 1, right = tx + tR + uL + 1, top = ty − tU − uD − 1, bottom = ty + tD + uU + 1, using the units.dat dimensions {L, U, R, D}. The unit's source is on the box perimeter if x ∈ {left, right} with top ≤ y ≤ bottom, or y ∈ {top, bottom} with left ≤ x ≤ right (signed). In that case point[0] = source, goal = source, `+0x150` = 0, count `+0x152` = 1, `+0x1e` = 1, `+0x1f` = 0, and it returns 1 without searching.
  5. r = `0x491f50`(ECX = context, EDX = next, stack [T]). If r ≠ 0, let L = the last stored point (`+0x88 + 4·(count − 1)`):
     - If reached `+0x1e` ≠ 0: when `final` = 0 and L = T, clear `+0x1e` (an intermediate target is not the goal); otherwise goal `+0x18` = L.
     - If reached = 0 and next = 0x1ffe: `+0x1e` = 1, `+0x1f` = 1 and goal = L.

     Return r.
- Callers/callees: `0x491210`, `0x4919b0`.
- Prior evidence: [local paths](../native-local-paths.md) (segment selection with targets two regions ahead, executed), [subunit/Scarab](../native-subunit-scarab.md).

### 0x00491f50 `LocalPathSearch` — A* over local geometry points
- Module: sai_pathcreate.cpp..sai_scripts.cpp · Relevance: simulation
- Status: specified
- Signature: ECX = path context, EDX = next region N (0x1ffe when none), stack [packed target T]; `ret 4`. Returns 1 iff point count `+0x152` > 0 (signed).
- Behavior:
  1. **Setup.**
     - `final` = (T = goal `+0x18`). `doubleCost` = N < 2500 and `IsRegionInaccessible` `0x481bb0(N)` = 0. `+0x166` = `+0x16a` = 0. S = source region `+0x160`. G = GetRegionAtPixel(goal).
     - The anchor is N if N < 2500, else G. Its ground neighbors come from `0x481ab0`. Each neighbor ≠ S gets region `+8` = 1 (the near marker).
     - Load the context `0x69d930`: `ImportGlobalContours` `0x488e10`(`*(*0x69b584 + 0x97a1c)`), `SetUnitTypeExtents` `0x4891c0`(unit type), `SetSearchSubjects` `0x4892d0`(unit, &T, target unit `+0xc`, &box `+0x10`), and reset the visited slabs `0x493200`.
     - Start node 0 at `0x69b788`: position = source, region S, bytes `+6..+0xb` = 0, 0, 0, 0, 0xff, 0, parent 0, h = 0x400000, g = 0, f = 0x400000. The heap holds only node 0; arena next = node 1. Counters: `goalFound`, `abort`, `inTarget` (open nodes in N), `near` (open nodes in near regions) are all 0.
  2. **Main loop** (while the heap is not empty). Pop the minimum: take the last entry, put it at slot 1 and call `0x4929b0(1)`.
     - If node.isGoal: `+0x1e` = 1; output this node.
     - If node.flags ≠ 0: `0x4930b0`(node, &node.flags).
     - Nodes used = (arena next − `0x69b788`) & ~31 bytes, counting node 0. If `inTarget` > 0, no goal is found yet and (`final` = 0 or used ≥ 150 nodes): `abort` = 1. If `near` ≠ 0, no goal is found yet and used ≥ 200 nodes: `abort` = 1.
     - If node.inTarget and `abort`: output this node.
     - node.closed = 1. If node.inTarget: `inTarget` −= 1. If node.inNear: `near` −= 1, and if `abort`, go to the tally.
     - If no goal is found yet, `abort` = 0 and node.flags ≠ 0: call `0x491ba0`(context, node). For each neighbor record (count `0x69d9a0`, records {x, y, flags, isGoal} at `0x69d9a4`, stride 8):
       - R = GetRegionAtPixel(x, y); inT = (R = N); inN = (region R `+8` ≠ 0).
       - A goal record sets `goalFound` = 1. A non-goal record with flags ≠ 0 is filtered by `0x4930b0` and skipped if its flags become 0. Records with flags 0 are kept.
       - Find an existing node with the same packed position by linear scan from node 1. Node 0 is never matched.
       - **New node** at the arena end: position, region R, parent = current, flags, depth = parent + 1. edge = ApproxDistance(point·256, parent·256), doubled as `(edge·512)/256` (signed) when `doubleCost` and R ∉ {N, S}. h = ApproxDistance(point·256, T·256), g = parent.g + edge, f = g + h. inTarget = inT, isGoal, inNear = inN, closed = (flags = 0). If flags ≠ 0 or isGoal: closed = 0, insert into the heap (inlined `0x492a30`: bubble up while the parent's f ≥ the new f), and add inT/inN to the counters. Then stop the record loop if the heap count = 150 or the arena is full (250 nodes).
       - **Existing node E:** skip if E is the current node's parent. edge as above from the current position; newG = current.g + edge. If newG < E.g (signed): E.parent = current, E.depth = current.depth + 1, E.g = newG. If E is open, `0x492900`(E, E.h + newG). If E is closed, it is reopened: E.f = E.h + newG, E.flags = record flags, E.closed = 0, E.isGoal = record isGoal, `0x492a30(E)`, and the counters are added. Then stop the record loop if the heap count = 150. Otherwise, if E is open, E.flags &= record flags.
       - After the records: `+0x16a` = max(`+0x16a`, heap count). If (count = 150 or arena full), no goal is found and `inTarget` = 0, go to the tally.
  3. **Tally** (heap empty, a near node popped during `abort`, or capacity reached). `+0x1d` = 1.
     - For nodes 1…end: if region `+8` ≠ 0 it is incremented, so the counter becomes 1 + the number of nodes in that region. Closed nodes are skipped. An open node with flags ≠ 0 is filtered by `0x4930b0`; if its flags are then nonzero it counts as `open` (and `openInG` when its region = G). An open node whose flags are 0, before or after the filter, is closed (and `inTarget` −= 1 if inTarget).
     - Let k = `open`, or, when `final`, k = `openInG` adjusted over the anchor neighbor list in order, skipping S: a counter < 2 adds 1 and stops; otherwise k = max(0, k − counter/2).
     - `exhausted` = (k = 0 and `inTarget` = 0). Node 0's h is recomputed as ApproxDistance(source·256, T·256).
     - **If exhausted:** best = node 0, bestH = node 0's h. For nodes 1…end with h < bestH (strict): accept every node when `final`, else only nodes in S. Then `+0x1e` = 1 and `+0x1f` = 1.
     - **Otherwise:** best = node 0, bestScore = 0x400000. Score = g + h/2 for regions G or N. Otherwise g·3/2 when the region is near-marked, g·2 when it is S, g·4 else (signed truncation). Closed nodes score ×32. The strict minimum wins.
  4. **Output.** `+0x166` = nodes used (including node 0). Walk best → parents, copying positions into a 128-DWORD stack array, and stop after 128. Call `0x492860`(ECX = context, EDX = copied count, stack [array]). Then reset region `+8` = 0 for every anchor neighbor ≠ S.
- Globals/fields: `0x69b788` arena, `0x69d6c8` heap, `0x69d924` count, `0x69d928` sentinel, `0x69d930` local context, `0x69b584` pathing, region `+8`.
- Callers/callees: `0x491c10`.
- Prior evidence: [local paths](../native-local-paths.md) (executed unobstructed and detour searches; the 150/200 fallbacks at `0x492170`/`0x49219b` are recovered here), [local heaps](../native-local-heaps.md).

### 0x00492860 `StoreLocalPathPoints` — reverse the parent chain into the context
- Module: sai_pathcreate.cpp..sai_scripts.cpp · Relevance: simulation
- Status: covered
- Signature: ECX = path context, EDX = n (chain length), stack [array, goal first]; `ret 4`.
