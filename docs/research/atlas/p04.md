# P04: Image records, IScript interpreter, image pools and persistence, placement grids and compression callbacks

This package spans the tail of the `cflingy.cpp..cimage.cpp` bracket, `cimage.cpp` itself and the objects that sort between `cimage.cpp` and `compress.cpp`. It falls into eight groups.

1. **Image state helpers** (`0x40ed30`–`0x40f890`, `0x411460`–`0x411840`). These set an image's drawing method, direction, flip, frame set, offsets and follow-main flag, look up LO overlay offsets, and release images back to their pools. Every method change reinstalls the update callback from `0x503044 + method*8` and the draw callback from `0x5030d4 + method*12` (normal) or `0x5030d8 + method*12` (mirrored); method 17 additionally forces WORD `+0x30` = `0x0230`. The method tables are listed in [P03](p03.md).
2. **Image pools** (`0x40f8b0`, `0x40f490`, `0x40fe50`). Five fixed pools exist: the main pool of 5000 images, 12 virtual health-bar images, 80 selection circles, 64 placement ghosts and 64 placement footprint boxes. Each has its own free list.
3. **Image initialization and resources** (`0x40fb50`–`0x40ff40`, `0x4101b0`). These initialize an image from `images.dat`, run its Init animation, load `images.dat`, `iscript.bin`, every GRP and LO file and two palette tables, and create overlays relative to an existing image.
4. **The IScript interpreter** `0x410480`, with its 69-entry dispatch table, and the animation installer `0x411730`.
5. **Image persistence** (`0x40f000`, `0x40f100`, `0x410090`, `0x4103c0`, `0x411300`). Save converts pointers to indices and writes live records compressed; load restores them and rebuilds the free list.
6. **Generic doubly linked list primitives** (`0x411900`–`0x4119a0`), used by every pool in the game.
7. **Resource decryption and an executable-signature check** (`0x4119f0`–`0x412120`). The first two decode encrypted font resources; the last four only gate launching `SystemSurvey.exe`.
8. **Building placement grids and tile-flag helpers** (`0x4122d0`–`0x413610`), plus the two PKWARE stream callbacks `0x413750`/`0x413790` used by the compressed save-chunk reader and writer in `compress.cpp`.

## Shared data and tables

**Image record** (`0x40` bytes; BWAPI `CImage`, confirmed by the code below): `+0x00` prev, `+0x04` next, `+0x08` image ID WORD, `+0x0a` drawing method BYTE, `+0x0b` direction BYTE (0..16 after quantization), `+0x0c` flags WORD, `+0x0e/+0x0f` signed BYTE x/y offset, `+0x10` IScript state (8 bytes: `+0x10` header offset WORD, `+0x12` program counter WORD, `+0x14` return address WORD, `+0x16` animation BYTE, `+0x17` wait BYTE), `+0x18` frame-set base WORD, `+0x1a` frame index WORD, `+0x1c/+0x1e` world x/y, `+0x20/+0x22` screen x/y, `+0x24/+0x26` crop x/y, `+0x28/+0x2a` visible width/height (all signed WORDs), `+0x2c` GRP pointer, `+0x30` drawing parameter DWORD, `+0x34` draw callback, `+0x38` update callback, `+0x3c` parent sprite.

Image flag bits: `0x01` dirty (needs redraw), `0x02` mirrored, `0x04` hold world Y, `0x08` directional (`images.dat` GfxTurns), `0x10` full IScript (`images.dat` UseFullIScript), `0x20` clickable, `0x40` hidden, `0x80` follow the main image's special-LO offset.

**Sprite fields used here**: `+0x08` sprite ID, `+0x0a` owner, `+0x0b` selection index, `+0x0c` visibility mask, `+0x0d` elevation, `+0x0e` flags (`0x20` hidden, `0x80` no-break), `+0x14/+0x16` position, `+0x18` main image, `+0x1c` image list head, `+0x20` image list tail.

**Execution contexts**: current unit `0x543300`, current Flingy `0x543304` (receives `sigorder`/`orderdone`), current Bullet `0x543308`. IScript data pointer `0x54330c`; its first DWORD is the offset of the ID index (pairs `{WORD id, WORD header offset}` terminated by id `0xffff`). A header's animation table starts at header `+8`, one WORD program counter per animation.

**`images.dat` descriptor** `0x5011a8` (14 columns of 999 entries, consumed by `0x4442b0`):

| Column | Destination | Size |
|---|---|---|
| GRP file (images.tbl index) | `0x511748` | 4 |
| GfxTurns | `0x5126e8` | 1 |
| Clickable | `0x512ad0` | 1 |
| UseFullIScript | `0x512eb8` | 1 |
| DrawIfCloaked | `0x5132a0` | 1 |
| DrawFunction | `0x513688` | 1 |
| Remapping | `0x513a70` | 1 |
| IScript ID | `0x513e58` | 4 |
| Shield overlay LO | `0x514df8` | 4 |

| Landing dust LO | `0x518c78` | 4 |
| Liftoff dust LO | `0x519c18` | 4 |

**Loaded resource tables**: GRP pointers `0x5436f8 + id*4`; LO pointers `0x596400 + (kind*999 + id)*4` with kinds 0 attack (`0x596400`), 1 damage (`0x59739c`), 2 special (`0x598338`), 3 landing dust (`0x5992d4`), 4 liftoff dust (`0x59a270`); shield LO pointers `0x59b210 + id*4`. LO data: DWORD frame count, DWORD point count, then a DWORD offset per frame (from LO start) to signed-byte `(x, y)` pairs. Damage-overlay point counts `0x543310 + id` (bytes). Tileset shift table `0x59c1b0` (256 bytes), selection-circle palette `0x594054` (24 bytes).

**Remapping table** `0x508828`: eight 20-byte records `{DWORD index, DWORD data pointer, char name[12]}`. Index 0 is empty; 1 `ofire`, 2 `gfire`, 3 `bfire`, 4 `bexpl`, 5 `trans50`, 6 `red`, 7 `green`. Drawing method 9 stores the data pointer of record `images.dat Remapping[id]` in image `+0x30`; save converts it back to the record index.

**Tileset names** `0x503398` (indexed by WORD `0x5264bc`): `badlands`, `platform`, `install`, `AshWorld`, `Jungle`, `Desert`, `Ice`, `Twilight`.

**Image pools** (all records `0x40` bytes):

| Pool | Records | Free head / tail | Notes |
|---|---|---|---|
| Main | `0x544698`, 5000 | `0x544694` / `0x592898` | All sprite images |
| Health bars | `0x5928a0`, 12 | `0x59289c` / `0x592ba0` | Image 560, method 11; virtual GRP headers `0x592ba8 + i*14` |
| Selection circles | `0x592c50`, 80 | `0x592ba4` / `0x594050` | Method 13 |
| Placement ghosts | `0x594070`, 64 | `0x59406c` / `0x595070` | Image 581 |
| Placement boxes | `0x595078`, 64 | `0x595074` / `0x596078` | Image 583, method 15; virtual GRP headers `0x596080 + i*14` |

A virtual GRP header is `{WORD frame count = 1, WORD width, WORD height, frame 0: BYTE x, BYTE y, BYTE width, BYTE height, ...}`; the owner fills the size per use.

**IScript dispatch table** `0x4111e4`: 69 handler addresses for opcodes `0x00..0x44`. Opcodes above `0x44` are skipped as one-byte no-ops before the table is consulted. Opcodes `0x0c`, `0x3e` and `0x43` point at the loop head `0x4104c4` and are one-byte no-ops. `0x1b` and `0x44` share `0x410d32`. Opcode `0x3d` uses `0x410633`. The other handlers are listed per opcode in the `0x410480` entry.

**Placement output** `0x675188 + entry*48`: 8 rows × 6 columns of per-cell error bytes. Tile flags are DWORDs at `[0x666454] + (y*width + x)*4`; map size in tiles is WORD `0x5264b4` (width) / `0x5264b6` (height). Tile bit `0x08000000` marks a tile occupied by a grounded building.

### 0x0040ed30 `StartDecloakingImage` — install decloak method on an image
- Module: cflingy.cpp..cimage.cpp · Relevance: render
- Status: covered
- Signature: `__fastcall`, ECX = image.
- Behavior: The new method is 4 when the old BYTE method is below 4, otherwise 7. It installs the update callback and the normal or mirrored draw callback for that method and writes WORD `+0x30` = `0x0308` (parameter 8, timer 3). The method-17 `0x230` write is unreachable here. Sets dirty.
- Callers/callees: `0x415990`. Prior evidence: [pixel effects](../native-pixel-effects.md).

### 0x0040ed90 `ConfigurePlacementBoxImage` — size and start a footprint-box image
- Module: cflingy.cpp..cimage.cpp · Relevance: ui
- Status: specified
- Signature: `__thiscall`, ECX = box image, stack = [sprite, packed offset (x low WORD, y high WORD), packed size (width low WORD, height high WORD)]; `ret 0xc`.
- Behavior:

  3. Flags WORD = 0; parent sprite = stack sprite; `+0x24..+0x2b` = 0; bounds `0x40ee70`; dirty.
  4. Looks up the header for `images.dat` IScript of the image's ID (583, written by the pool initializer) with `0x40f340`. Installs animation 0 inline (PC from header entry 0, wait 0, return 0) and runs `0x410480`(state `+0x10`, no-op 0, output null).

- Callers/callees: `0x40ebd0`.
- Prior evidence: none.

### 0x0040ee70 `UpdateImageBounds` — world and clipped screen rectangle from the GRP frame
- Module: cflingy.cpp..cimage.cpp · Relevance: render
- Status: covered
- Signature: `__fastcall`, ECX = image.
- Behavior: As in [image geometry](../native-image-geometry.md). World x = sprite x + signed offset + (`fx − W/2`, or `W/2 − fw − fx` when mirrored). World y is updated only without flag 4: sprite y + signed offset + `fy − H/2`. W and H are unsigned canvas halves. Screen x/y subtract camera DWORDs `0x543218/0x54321c`. A negative screen coordinate becomes 0, its magnitude becomes the crop, and the width/height shrinks by the same amount. Width/height are then limited to `640 − screen x` and `400 − screen y` (signed comparison). There is no clamp to zero.
- Callers/callees: `0x40ed90`, `0x40f6e0`, `0x40fb50`, `0x411460`, `0x415700`, `0x415750`, `0x415c00`, `0x416520`, `0x4165d0`.
- Prior evidence: [image geometry](../native-image-geometry.md), [image initialization](../native-image-initialization.md).

### 0x0040f000 `ImagesPointersToIndices` — pre-save conversion of the main image pool
- Module: cflingy.cpp..cimage.cpp · Relevance: simulation
- Status: specified
- Signature: no arguments.
- Behavior: For each of the 5000 main-pool records in ascending order:
  1. Zero the draw `+0x34` and update `+0x38` callbacks.
  2. GRP `+0x2c`: when nonnull, scan `0x5436f8[i]` for `i` from 0 while `i < N`, where N = 999 if `0x4635b0()` (expansion data flag `0x66cac0`) is nonzero, else 755. Store `i+1` at the first match, or 0 if not found.
  3. Method 11 (health bar): `+0x30` = packed unit ID from `0x428bd0` (pool index + 1 in bits 0..10, unit byte `+0xa5` shifted left by 11; 0 for null or an index above 1700). Method 9 (remap): `+0x30` = the remapping-table index 1..7 whose data pointer matches, scanning from 7 down to 1; 0 if none matches.
  4. Parent sprite `+0x3c` = sprite index through `0x416090` (`(ptr − 0x5af238)/0x24 + 1`, 0 for null).
  5. Links `+0x00/+0x04` = `(ptr − 0x544698)/0x40 + 1`, 0 for null.
- Callers/callees: `0x411300`.

### 0x0040f100 `ImagesIndicesToPointers` — post-save/post-load restoration of the main image pool

- Status: specified
- Signature: no arguments.

### 0x0040f1c0 `SetImageDirection` — apply a quantized 0..32 direction
- Module: cflingy.cpp..cimage.cpp · Relevance: render
- Status: covered
- Signature: `__thiscall`, ECX = image, stack = [BYTE direction]; `ret 4`.
- Behavior: Does nothing without flag 8. Values above 16 become `32 − d` with mirror 1, otherwise mirror 0. ### 0x0040f280 `SetImageMirror` — IScript setflipstate

### 0x00413750 `DclReadCallback` — PKWARE DCL input callback over a memory buffer
- Module: cimage.cpp..compress.cpp · Relevance: simulation
- Status: specified
- Signature: `__cdecl (char *buf, unsigned *size, stream *s)`; returns bytes supplied.
- Behavior: The stream record (`[0x5a52b0]`, 24 bytes) is `{+0 input base, +4 input position, +8 output base, +0xc output position, +0x10 input size, +0x14 output capacity}`. `n = min(*size, input size − input position)` (unsigned). It copies n bytes from input base + position to buf (`memmove 0x4d16a0`), advances the position and returns n.
- Callers/callees: passed by pointer to implode `0x401000` (from chunk compressor `0x413940`) and explode `0x401ae0` (from chunk decompressor `0x413a40`). These serve every compressed save chunk.

### 0x00413790 `DclWriteCallback` — PKWARE DCL output callback with overflow accounting
- Module: cimage.cpp..compress.cpp · Relevance: simulation
- Status: specified
- Signature: `__cdecl (char *buf, unsigned *size, stream *s)`.
- Behavior: If `output position + *size ≤ output capacity`, it copies `*size` bytes to output base + position. In every case it then adds `*size` to the position, so overflow is recorded without writing. The compressor `0x413940` uses this: when the result is not smaller than the input it keeps the raw chunk. The decompressor `0x413a40` rejects a chunk whose output position exceeds `0x2000`.
- Callers/callees: as `0x413750`.
