# P22: Program start-up and main loop, archives and spawn check, control groups, image GRP loading, health bars, cipher, remap tables and vision templates

This package covers `0x4634e0`–`0x467e00`: `grid.cpp`, `group.cpp`, the objects between `group.cpp` and `help.cpp`, `help.cpp`, the objects between `help.cpp` and `init.cpp`, `init.cpp`, `league.cpp`, `light.cpp`, `los.cpp` and the objects between `los.cpp` and `maphdr.cpp`. Its 101 functions form nine groups.

1. **Encrypted `font\font.*` resources and the spawn flag** (`grid.cpp`, `0x4634e0`–`0x4638a0`). Start-up loads `font\font.gid`, `font\font.clh` and `font\font.ccd`. The first two are decoded with a fixed key; the decoded `font.gid` string is the key for `font.ccd` and for every encrypted `font\*.fnt`. The **spawn flag** `0x5085c8` is 0 when `font.ccd` decodes to `"sgubon"`. The **expansion data flag** `0x66cac0` is 1 when `rez\epilogX.txt` exists in an open archive.
2. **Image GRP and LO loading** (`0x4639b0`–`0x463c20`). Parallel asynchronous loads of every `images.dat` GRP and overlay file, shared between identical table entries, and the GRP frame-header accessor used by dialogs.
3. **Control groups** (`0x463d60`–`0x4643c0`). 18 groups per player: 0–9 are the hotkey groups, 10–17 are eight automatic "recent selection" groups with age stamps. Alt-click uses them to select the group a unit was last selected with.
4. **Map VCOD hash** (`0x464560`) and the **Help dialog** (`0x464720`–`0x464850`).
5. **Health bars** (`0x4648a0`–`0x464f90`), covered by [native health bars](../native-health-bars.md).
6. **IDEA block cipher** (`0x464fb0`–`0x465400`), covered by [native font decoder](../native-font-decoder.md).
7. **Start-up and archives** (`0x465470`–`0x4662b0`): CD-archive search, data-version check, archive opening, font sets, command-line switches, `local.dll` and the version string.
8. **League reporting** (`league.cpp`, `0x4662c0`–`0x466620`): Battle.net league replay copies and result text. Excluded.
9. **Remap tables and vision templates** (`light.cpp`, `los.cpp`, `0x4666c0`–`0x466e40`), then **the program entry and main loop** (`0x466f20`–`0x467e00`): single-instance check, user-data directory selection and migration, system checks, window creation, the main state loop and the game run wrapper.

## Shared conventions

- Storm and runtime helpers: `0x444890`(ECX = path, EDX = buffer or 0, stack `[size out, file, line]`) loads a whole file and is fatal when it is missing; `0x444990`(ECX = path, EDX = buffer or 0, stack `[size out, quiet, search scope, file, line]`) is the same but with `quiet` ≠ 0 a missing file (errors 2 and `0x3ee`) is not fatal and returns 0. `0x444ca0`(ECX = pointer, EDX = file, stack line) frees. `0x4c13b0`(ECX = TBL, EDX = index) returns TBL string *index* (0 → null; out of range → the empty string `0x4ec14e`).
- Exit callbacks: `0x4ce940`(ECX = function) registers a cleanup function in a 32-entry table (`0x6d3178`, allocated on first use; a function already present is not added again; a full table is a fatal "APPADDEX:1" error). `0x4cf730`(CL = suppress Storm error dialogs) runs the cleanup and terminates the process with `_exit`.
- `0x4cb710`(ECX = dialog resource ID) shows a modal dialog from `local.dll` (`0x6d0c54`) and returns its result; the start-up warning wrappers `0x4ceaa0`, `0x4ceac0`, `0x4cec10`, `0x4cec30` and the "insert CD" prompt `0x4cebf0` return 1 when the user pressed OK.
- Unit references in control groups are packed values (`0x428bd0` encodes, `0x428b50` decodes and returns 0 for dead or recycled units). `0x4291b0`(ECX = unit) is `IsMultiSelectable`; `0x429250` is `IsRallyProducer`; `0x41b250` flashes a rally point; `0x423120` cancels targeting/placement modes.
- Players: `0x508d54` is the local player's slot index and `0x508d50` the local player ID. During command processing `0x508d48` is the slot and `0x508d44` the player of the command being executed (the issuing player).

## Data structures and tables

**Spawn resources.** `0x66cac4`/`0x66cac8`: raw `font\font.gid` buffer and size. `0x66cacc`/`0x66cad0`: raw `font\font.clh` buffer and size. `0x5085c8`: spawn flag (DWORD). `0x66cac0`: expansion data flag (DWORD). The fixed key comes from `0x448f40`(ECX = 20-byte buffer, EDX = 20): 19 non-zero CRT-generator bytes from seed `0x150b` plus a NUL ([font decoder](../native-font-decoder.md)). `0x4119f0` `DecryptResource`(ECX = buffer, EDX = size, stack key) decodes in place and returns the logical length or 0. `0x476e20`(ECX = text, EDX = limit, stack `[max, 0, 0]`) returns the length including the NUL when the text is terminated within `min(limit, max)` bytes and contains no byte `0x01`–`0x1f`, else 0.

**Control groups** `0x527140` (`0x1b00` bytes): u32 packed unit references at `0x527140 + ((group + slot·18)·12 + k)·4`, `group` 0–17, `k` 0–11. A group's length is the number of entries before the first 0 (at most 12). **Automatic-group stamps** `0x66cad8` (`0x80` bytes): u16 `0x66cad8 + (slot·8 + a)·2` for automatic group `10 + a`, a = 0–7; each holds the low 16 bits of the command-turn counter `0x672658` when that group was last written or selected. The per-player selections that commands maintain are `0x6a5ef0 + slot·0x30` (12 unit pointers, null-terminated). The double-tap memory of the local hotkey code is `0x67264c` (group, `0xff` = none) and `0x672650` (tick).

**GRP header** (`0x463ae0`, `0x463bd0`): u16 frame count (bit 15 masked off), u16 width, u16 height, then one 8-byte record per frame at `+6`: u8 x, u8 y, u8 width, u8 height, u32 data offset.

**Health-bar class tables** (`0x5085d0`…, read by `0x464d20` and its row drawers; colors are indices into the 19-entry `game\thpbar.pcx` palette at `0x66cb5c`):

| Address | Contents |
|---|---|
| `0x5085d0` | 5-row HP classes, 6 bytes each `{min %, row colors ×5}`: `{66, 18,0,1,2,18}`, `{33, 18,3,4,5,18}`, `{0, 18,6,7,8,18}` |
| `0x5085e4` | 5-row energy/timer class: `{0, 18,12,13,14,18}` |
| `0x5085ec` | 5-row empty colors: 18, 15, 16, 17, 18 |
| `0x5085f4` | 7-row HP classes, 8 bytes each: `{66, 18,0,0,1,1,2,18}`, `{33, 18,3,3,4,4,5,18}`, `{0, 18,6,6,7,7,8,18}` |
| `0x50860c` | 7-row empty colors: 18, 15, 15, 16, 16, 17, 18 |
| `0x508614` | shield fill colors (4 rows): 18, 10, 11, 18 |
| `0x508618` | shield empty colors: 18, 16, 17, 18 |

**Help dialog interact table** `0x5085cc` (byte size 4, one entry): control 1 → `0x464810`.

**VCOD jump table** `0x464700` (8 entries, opcode 0–7): `0x464603` xor, `0x46460a` add, `0x464611` subtract, `0x464618`/`0x464635`/`0x464655` table XOR (opcodes 3, 4, 5 are identical), `0x464672` rotate left, `0x4646a0` rotate right.

**IDEA contexts** `0x66cb70 + context·0x68` (three contexts, 52 u16 subkeys each, `0x138` bytes).

**Archive handles**: `0x66ccd0` `Stardat.mpq` (priority 2000), `0x66ccc8` `patch_rt.mpq` (7000), `0x66ccd4` `Broodat.mpq` (2500), `0x66cccc` the CD archive (1000). Path buffers: `0x66cde0` the `patch_rt.mpq` path, `0x66cee8` the archive list text (`"<Broodat path>;<Stardat path>"`, or only the Stardat path), `0x66ccd8` the executable path. Program information record `0x66cca8` (20 bytes): `{0x14, 0x508620 version text, 0x66ccd8, 0x66cee8, 0x66cde0}`.

**Font slots** `0x6d3024`, `0x6d3028`, `0x6d302c`, `0x6d3030` and the font-set mode `0x66ccc0`:

| Mode | Set by | `0x6d3024` | `0x6d3028` | `0x6d302c` | `0x6d3030` |
|---:|---|---|---|---|---|
| 1 | `0x465ce0` (start-up and glue) | font10 | font14 | font16 | font16x |
| 2 | `0x465c40` (game start) | font8 | font10 | font16 | font16x |

**Tileset remap records** `0x508828` (8 records of 20 bytes `{u32 remapping index, u32 table pointer, char name[12]}`; record 0 is empty): 1 `ofire`, 2 `gfire`, 3 `bfire`, 4 `bexpl`, 5 `trans50`, 6 `red`, 7 `green`. The table pointers are therefore at `0x508840 + 20·(index − 1)` and the names at `0x508844 + 20·(index − 1)`. The u32 that follows each name is the next record's index, not a property of the record: after `green` the bytes are unrelated text. Image drawing method 9 reads the pointer as `[0x50882c + images.dat Remapping·20]` (`0x40fc50`, load conversion `0x40f100`), and the save conversion `0x40f000` turns a pointer back into index 7…1 ([P04](p04.md)). Other light globals: `0x66fd20` the 256-byte "color is cycled" flags; `0x66dd20` the `dark.pcx` shading table (`0x2000` bytes = 32 rows of 256); `0x501021` and `0x66fc20` two 256-byte identity remaps.

**Main-loop state jump table** `0x467b68` (game state `0x6662b8`, values 0–10): 0 `0x467ada` intro videos, 1 `0x467ad1` start a game, 2 `0x467b5f` exit, 3 `0x467aa5` run a game, 4 `0x467b1d` glue, 5 `0x467ac7`, 6 and 7 `0x467b1d` glue, 8 `0x467b27` credits, 9 `0x467b36` epilog, 10 `0x467aac`. Values above 10, and negative values (the WORD is sign-extended and compared unsigned), also exit.

**User-data folders** migrated by `0x467330` (string table built on the stack): `characters\`, `Errors\`, `maps\replays\`, `maps\download\`, `maps\save`, `save\`, `leagues\`.

## Functions

### 0x004634e0 `GetSpawnKeyHash` — hash of the decoded `font.gid` key
- Module: grid.cpp · Relevance: data
- Status: specified
- Signature: no arguments; returns u32.
- Behavior: Allocates a copy of the raw `font.gid` buffer (size `0x66cac8`, line `0x42`) and copies it. Builds the fixed key (`0x448f40`). L = `0x4119f0`(copy, size, key). If L ≠ 0 and L < size (unsigned), sets copy[L] = 0 and validates with `0x476e20`(copy, `0x80`, L+1, 0, 0); on success keeps the copy, otherwise (and when L fails the test) frees it (line `0x4d`) and uses a null pointer. Returns `SStrHash`(copy, 0, 0). A non-null copy is overwritten with zeros for its `SStrLen` and freed (line `0x5c`).
- Callers/callees: four callers, all multiplayer. `CreateMultiplayerGame` `0x475040` ([P26](p26.md)) stores the result in the game header `+0x2c` (offset `0x6728fc` once copied to `0x6728d0`). `0x4714b0` writes the spawn flag to its outgoing packet `+0xd` and this hash to `+0xe`; `0x470af0` recomputes it and compares it with a received packet's `+0xe` when that packet's `+0xd` is nonzero; `0x475610` recomputes it and compares it with a game header's `+0x2c` when the local spawn flag is set. Single player creates its game through `CreateLocalGame` `0x475220`, which never writes `+0x2c` (the field keeps the zero from the header memset in `0x45bfc0`, or a loaded save's stored value). No single-player logic calls it or reads the field back.

### 0x004635d0 `DecodeSpawnResources` — heap copies of decoded `font.gid` and `font.clh`
- Module: grid.cpp · Relevance: data
- Status: specified
- Signature: `__fastcall`, ECX = `char**` for the key or 0, EDX = `char**` for the spawner name or 0.
- Behavior: For each requested output: allocate (`font.gid`: size `0x66cac8`, line `0x42`; `font.clh`: size `0x66cad0`, line `0x46`) and copy the raw buffer. Then for the key output, then the name output: build the fixed key (`0x448f40`), L = `0x4119f0`(copy, size, fixed key); accept when L ≠ 0, L < size (unsigned) and, after writing NUL at L, `0x476e20`(copy, `0x80`, L+1, 0, 0) ≠ 0. A rejected copy is freed (lines `0x4d` and `0x50`) and its output set to 0. Both resources use the fixed key; `font.clh` does not use the `font.gid` key.
- Callers/callees: `0x463710` (key), `0x4657f0` (key for fonts), `0x45ab00` (spawner name for the main-menu version label), `0x46f330`. Prior evidence: [font decoder](../native-font-decoder.md), which validates the `font.gid` carrier decode on retail data.

### 0x00463710 `CheckSpawnResource` — does `font.ccd` decode to the expected text
- Module: grid.cpp · Relevance: data
- Status: specified
- Signature: `__fastcall`, ECX = path (`"font\font.ccd"`), EDX = expected text (`"sgubon"`, `0x4ee33c`); returns 0/1.
- Behavior: Loads the file quietly (`0x444990`, quiet 1, scope 0, line `0x89`). Missing file → 0. With a nonzero size it decodes the key (`0x4635d0`(&key, 0)). With a key it decodes the file in place, L = `0x4119f0`(data, size, key); when L ≤ size (unsigned) the result is `SStrCmp(data, expected, L) == 0`. A zero L compares no characters and therefore counts as a match. Frees the file (line `0xa0`), zero-fills and frees the key (line `0x5c`). Returns the result (0 when the size is 0 or the key is rejected).
- Note: Ghidra marks the decode and compare blocks unreachable and shows a constant 0, because it lost the ECX argument of `0x4635d0`. The instructions execute them; see the contradiction note under `0x4638a0`.
- Note: [V01 item 2](v01.md) states the polarity the other way round ("returns 0 on a match"). The sequence after `SStrCmp` (`neg; sbb; inc` at `0x463773`–`0x463777`) yields 1 when `SStrCmp` returns 0, so this function returns 1 on a match. V01's conclusion (flag 0 on this installation) is unaffected, because `0x4638a0` stores the negation.

### 0x004638a0 `LoadSpawnResources` — load `font.gid`/`font.clh` and compute the spawn flag
- Module: grid.cpp · Relevance: data
- Status: specified
- Signature: no arguments.
- Behavior:
  1. Formats `"font\font.gid"` (`"%s\%s.gid"` with `"font"` twice) and loads it whole (`0x444890`, size out `0x66cac8`, line `0x6a`). A loaded file of size 0 is freed (line `0x76`) and treated as absent. Stores the buffer (or 0) in `0x66cac4`.
  2. The same for `"font\font.clh"` into `0x66cacc`/`0x66cad0`.
  3. Formats `"font\font.ccd"` and sets `0x5085c8` = (`0x463710`(path, `"sgubon"`) == 0).
- Callers/callees: `0x465de0`, which registers `0x4637d0` right after.
- Contradiction (resolved): [P19](p19.md) originally stated that `0x463710` always returns 0, so the spawn flag is always 1 and PalCs is never loaded. That followed Ghidra's unreachable-block removal, not the instructions; P19 is corrected. A host decode of the retail `StarDat.mpq` `font\font.ccd` (with the `font.gid`-derived key, the same pipeline as [font decoder](../native-font-decoder.md)) gives `"sgubon\0"`, so the flag is 0 on this installation. [P20](p20.md) is right that the flag is the result of the decode-and-compare. It is data-dependent: the flag is 0 exactly when the shipped `font.ccd` decodes with the `font.gid` key to text that matches `"sgubon"` over the decoded length. A full retail installation must produce 0, because a flag of 1 refuses single player ([P20](p20.md) `0x45a8b0`, network.tbl 103) and the retail game allows it.

### 0x00463a30 `BeginLoadImageGrp` — start or share one GRP load
- Module: group.cpp · Relevance: data
- Status: specified
- Signature: `__fastcall`, ECX = output pointer table, EDX = `images.tbl`, stack `[index i, GRP column, request record, handle slot]`, `ret 0x10`; returns the GRP pointer.
- Behavior: id = column[i] (u32). id 0 → returns 0 (nothing started). Scans j = i−1 down to 0 for column[j] = id and returns output[j] for the first match. Otherwise creates a manual-reset event (`CreateEventA(0, TRUE, FALSE, 0)`) into request `+0x10`, formats `"unit\%s"` with TBL string (id low 16 bits), and starts the read with `0x444b10`(path, &buffer (0 → allocate), size out 0, request, line `0xed`), storing the file handle in the slot. Returns the newly allocated buffer, whose contents arrive asynchronously.

### 0x00463ae0 `LoadImageGrps` — load every image GRP and resolve frame offsets
- Module: group.cpp · Relevance: data
- Status: specified
- Signature: `__fastcall`, ECX = output table (`0x5436f8`), EDX = GRP column (`0x511748`), stack `[images.tbl, unused (999), request records, handle array]`, `ret 0x10`.
- Behavior:
  1. n = `0x40f680()` (999 with expansion data, else 755). Zeroes n 20-byte request records and n handles.
  2. For i = 0…n−1: output[i] = `0x463a30`(i, …); then pumps messages (`0x4401c0`(1)) and presents a frame (`0x4c5360`).
  3. Waits for all reads (`0x444750`(requests, handles, n)).
  4. For i = n−1 down to 0: g = output[i]; skips g when any j < i has output[j] = g; otherwise for each frame k of g (count = u16 `+0` & `0x7fff`, last frame first) replaces the u32 at `+0x0a + 8k` by `(value & 0x7fffffff) + g`, turning offsets into absolute pointers. A null g with no earlier null entry would be dereferenced; stock `images.dat` references a GRP for every image.
- Callers/callees: `0x40ff40` (with `0x6662c4` = low-memory flag so `lowm\` variants are preferred). Prior evidence: [image geometry](../native-image-geometry.md).

### 0x00463bd0 `GetGrpFrame` — frame record and size of a GRP
- Module: group.cpp · Relevance: render
- Status: specified
- Signature: `__fastcall`, ECX = GRP (with relative offsets), DX = frame, stack `[frame out (8 bytes), size out (2 × u16)]`, `ret 8`.

### 0x00464030 `SelectRecentGroupOfUnit` — Alt-click group recall
