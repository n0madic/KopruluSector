# P07: Cloak state, player colors, combat targeting, damage, attack orders, Capture the Flag and spatial queries

This package covers the second half of the object that sorts between `ctxthelp.cpp` and `cunitinit.cpp` (`0x41d300`–`0x422150`). Most of it is the unit combat layer: weapon and target predicates, target maintenance and AI retargeting, the damage entry points, on-hit reactions, the firing/cooldown path and the order handlers that the main order dispatcher `0x439420` (and the hidden-unit dispatcher `0x439e20`) call. The other groups are cloak status helpers, the player-color tables used by drawing and selection circles, Capture the Flag (CTF) orders and messages, and three spatial queries over the sorted unit-bound arrays.

1. **Cloak status** (`0x41d300`–`0x41d4c0`): start cloaking, decloak, and the status-bit setter used by cloak image callbacks.
2. **Player colors** (`0x41d460`–`0x41d7b0`): color assignment `0x5264fc`, the 12×8 color rows `0x529056`, minimap colors `0x5290b6`, the selection-circle color class `0x52904a` and the drawing remap.
3. **Weapons and targeting predicates** (`0x41d8f0`–`0x41df90`, `0x41f320`, `0x41fa00`–`0x420120`, `0x420a90`–`0x421370`): attack capability, weapon target flags, range, facing, dodge/miss chance, life values and target choice.
4. **Damage** (`0x41dfc0`–`0x41e2f0`, `0x4203d0`, `0x4212b0`, `0x420190`, `0x421180`): covered by [damage](../native-damage.md); this package adds the reaction and flee details.
5. **Order handlers** (`0x41e370`–`0x41f300`, `0x420600`–`0x420770`, `0x420bd0`, `0x4213c0`–`0x4214d0`): Guard, PlayerGuard, AttackUnit, AttackFixedRange, AttackMove, AI orders, Patrol, Hold, Bunker/Tower/Turret orders, Nuke, Suicide (Sap) and CTF orders.
6. **Firing** (`0x41f4a0`–`0x41f630`, `0x420030`, `0x420970`): bullet spawning for IScript attack opcodes and the cooldown/animation writer.
7. **Spatial queries** (`0x4217f0`–`0x421dc0`): swept and point queries over the sorted X/Y bound arrays.

## Shared data and tables

**Unit fields** follow BWAPI `CUnit` (confirmed at each use): `+0x08` HP (×256), `+0x0c` sprite, `+0x10/+0x12` move target, `+0x14` move-target unit, `+0x1c/+0x1e` next target waypoint (facing waypoint), `+0x20` movement flags (bit 2 moving, bit 8 attacking), `+0x21` heading, `+0x23` velocity direction, `+0x28/+0x2a` position, `+0x4c` owner, `+0x4d` order, `+0x4e` order state, `+0x4f` order signal, `+0x54` main order timer, `+0x55/+0x56` ground/air cooldown, `+0x58/+0x5a` order-target position, `+0x5c` order-target unit, `+0x60` shields (×256), `+0x64` type, `+0x6c` next unit of same owner, `+0x70` subunit (or parent, for a subunit), `+0x74` order queue head, `+0x7c` auto-target, `+0x80` connected unit, `+0x85` order throttle, `+0x8f` kill count, `+0x90` last attacking player, `+0x91` secondary-order timer, `+0x93` user-action flags, `+0x94` button set, `+0x96` cloak counter, `+0xa6` secondary order, `+0xc0` carried powerup / Interceptor parent, `+0xc8/+0xc9` hangar counts, `+0xdc` status, `+0xe4` detection mask, `+0xf0/+0xf4` cloaked-list links, `+0x105` pathing flags, `+0x112` matrix HP, `+0x115` stim, `+0x116` ensnare, `+0x117` lockdown, `+0x118` irradiate, `+0x119` stasis, `+0x123` blind, `+0x124` maelstrom, `+0x126` acid spores, `+0x134` AI record (`+8` AI type, `+0x12/+0x14` guard home), `+0x13c/+0x140/+0x144/+0x148` indexes of the unit's left/right/top/bottom records in the sorted bound arrays.

**Status bits** (`+0xdc`, names after OpenBW where BWAPI differs): `0x1` completed, `0x2` grounded building, `0x4` in air, `0x8` (set by target acquisition for Carrier/Reaver out of range), `0x10` burrowed, `0x20` in bunker, `0x80` (unnamed; set on an abandoned chase target), `0x100` requires detection, `0x200` cloaked, `0x400` disabled, `0x1000` order not interruptible, `0x2000` IScript nobrk, `0x8000` cannot attack, `0x10000` can turn, `0x20000` can move, `0x80000` immovable, `0x4000000` invincible, `0x8000000` ready to attack ("target switching" in earlier docs), `0x20000000` cooldown upgrade, `0x40000000` hallucination, `0x80000000` lifetime expired / self-destructing.

**units.dat columns** (descriptor at `0x5014ec`, 228 entries): `0x520458` shield enable (byte), `0x520540` shields (word), `0x520708` HP (dword ×256), `0x521008` attack-unit order, `0x5211d8` ground weapon, `0x5213a8` air weapon, `0x521660` special-ability flags (dword: `0x1` building, `0x8` worker, `0x10` subunit, `0x40` hero, `0x4000` robotic, `0x10000` organic, `0x100000` burrowable, `0x20000000` invincible, `0x40000000` mechanical), `0x5219f0` target-acquisition (seek) range, `0x521ad8` sight, `0x521ca8` size, `0x521d90` armor, `0x521e78` right-click action, `0x522728` placement box (2 words), `0x522c38` dimensions (left, up, right, down words), `0x524290` destroy score.

**weapons.dat columns** (descriptor at `0x501828`, 130 entries): `0x524f18` flingy (dword; 0 = no bullet), `0x5251a8` target flags (word), `0x5252b0` minimum range, `0x5254b8` maximum range, `0x5256c0` damage upgrade, `0x525748` damage type, `0x5257d0` behavior, `0x525b78` outer splash radius (word), `0x525c80` damage (word), `0x525d88` damage bonus (word), `0x525e90` cooldown, `0x525f18` damage factor, `0x525fa0` attack angle, `0x5260b0` forward offset, `0x526138` upward offset. Weapon ID `0x82` (130) means none.

**orders.dat columns used here**: `0x51ae40` "targets enemies" and `0x51b5c0` (OpenBW `unk11`, the "flee when hit" flag).

**Order IDs** used here (Teippi names): 0 Die, 2 Guard, 3 PlayerGuard, 4 TurretGuard, 5 BunkerGuard, 6 Move, 0x0a AttackUnit, 0x0b AttackFixedRange, 0x0e AttackMove, 0x12 TowerGuard, 0x13 TowerAttack, 0x16 TurretAttack, 0x17 Nothing, 0x60 Pickup4, 0x62 SiegeMode, 0x63 TankMode, 0x6b HoldPosition, 0x6d Cloak (secondary), 0x76 Unburrow, 0x7d NukeLaunch, 0x7f NukeUnit, 0x80 NukeGround, 0x81 NukeTrack, 0x86 SapUnit, 0x87 SapLocation, 0x98 Patrol, 0x99 CtfCopInit, 0x9a CtfCopStarted, 0x9b CtfCop2, 0x9c ComputerAI, 0x9d AiAttackMove, 0x9e HarassMove, 0xa0 AiGuard, 0xa3 ComputerReturn, 0xb0 Heal. Earlier docs call 0x9d "ComputerAttack" and 0x9e "ComputerAttackMove"; the numbers are the same.

**Order-queue helpers** (from [primary orders](../native-primary-orders.md)): `0x42a2c0` issue order (ECX unit, stack order), `0x42a340` issue at position, `0x42a380` issue at unit, `0x42a3e0` issue at packed position and unit, `0x42a5a0` end current order, `0x429d00` clear status `0x1000` then `0x42a5a0`, `0x429520` insert-after wrapper (order, x, y, anchor), `0x429e90` insert-before (order, packed, target, anchor), `0x429da0` insert-before at a unit's position, `0x429c40`/`0x429b70` insert before the queue head or append when empty, `0x429ee0`/`0x429f10` append with tail pruning, `0x429eb0` simple append, `0x42a1e0` set secondary order (clears `+0xe8`, `+0xec`, `+0xe2` when it changes).

**Color tables.** `0x5264fc`: 8 dwords, color assignment per player slot (identity 0..7 after `0x41d570`). `0x529056`: 12 rows of 8 palette bytes from `game\tunit.pcx` (96 bytes). `0x5290b6`: 12 minimap color bytes from `game\tminimap.pcx`. `0x52904a`: 12 bytes, selection-circle color class per owner (0 self, 1 ally, 2 enemy). `0x5d6e38`: current draw color. `0x501029/0x50102d`: entries 8..15 of the 256-byte drawing remap at `0x501021`.

**Sorted bound arrays** (the unit finder, see [placement](../native-placement.md) and [movement collision](../native-movement-collision.md)): count `0x5c99b0`; X records `{unit index, coordinate}` at `0x5c99b8`, Y records at `0x5d03f8`; unit index `i` resolves to `0x5da250 + i*0x150` through `0x4255f0`. Result lists go to `0x5d88f8` at cursor `0x5d6e5c`; query depth `0x5d6e48` with saved cursors `0x5d6e4c[]`; release is `0x4222b0`. `0x5d6e40`/`0x5d6e44` are the largest unit width/height.

**Seek-range switch** `0x41f430` (7 targets, index bytes at `0x41f44c` for IDs 0..0x4e): ID 0 → `0x41f370` (upgrade 0x10, +1); IDs 3,4 → `0x41f3e7` (upgrade 0x36, +3); IDs 0x11,0x12 → `0x41f40e` (expansion, +3); ID 0x26 → `0x41f39b` (upgrade 0x1e, +1); ID 0x42 → `0x41f3a2` (upgrade 0x21, +2); ID 0x4e → `0x41f3c9` (expansion, +2); all others → `0x41f41d` (no bonus).

**Weapon-range switch** `0x420fe8` (index bytes at `0x421004`): the same ID grouping, resolved in [unit AI](../native-unit-ai.md) static evidence.

**Flee distances** `0x5031ac`: 5 dwords `192, 128, 64, 32, 16`.

**CTF placement-error strings** `0x508d90`: word table indexed by the placement-validator result; entries 1..11 are `0x355 0x354 0x356 0x358 0x35c 0x35d 0x35e 0x35b 0x35a 0x359 0x357` (entry 0 is 0; the following word `0xf44c` is unrelated data, not a twelfth entry).

### 0x0041d300 `StartCloakingWithUiRefresh` — begin cloaking (Spider Mine variant)
- Module: ctxthelp.cpp..cunitinit.cpp · Relevance: simulation
- Status: specified
- Signature: `__fastcall`, ECX = unit; no return value.
- Behavior: Calls `0x4340d0` (post-increments cloak counter `+0x96`; when the old value was 0, status `0x100` is clear and `+0xf4` is 0, links the unit at the head of the cloaked-unit list `0x665d40` through `+0xf0/+0xf4` and refreshes the UI with `0x4a7ed0`). If not a replay (`0x67cc90 == 0`) and the owner is the local player `0x508d50`, refreshes the UI with `0x4a7ed0`. Clears `+0x91`, switches the sprite images to cloaking draw mode with `0x415e50`(ECX = sprite, 3, 0, 0), sets status `0x300`, sets secondary order `0x6d` (Cloak) with `0x42a1e0`, and sets detection mask `+0xe4 = 0x80000000`.
- Callers/callees: called by the Spider Mine order `OrderVultureMine` `0x436cf0` ([P12](p12.md)) at `0x436d58`, right after burrowing (`0x43d940`), for non-hallucinations. Ghidra originally missed this caller; an earlier version of this entry called the function unreferenced. `0x41d410` is the other variant.
- Prior evidence: none.

### 0x0041d360 `Decloak` — remove cloaking and play the decloak sound
- Module: ctxthelp.cpp..cunitinit.cpp · Relevance: simulation
- Status: specified
- Signature: `__thiscall`, ECX = unit, stack = [sound ID]; `ret 4`.
- Behavior:
  1. If the unit is not burrowed (status `0x10` clear), plays the sound with `0x446940`(ECX = sound, EDX = unit, 1, 0).
  2. If not a replay and the owner is the local player, refreshes the UI (`0x4a7ed0`).
  3. Burrowed: `0x4174a0`(sprite) resets images whose draw method is 2..7 to method 0, `0x417460`(sprite) marks images dirty (an image whose ID flag `0x5132a0[id]` is 0 and whose flag `0x40` is set gets `0x40` cleared and `0x1` set), then status `&= ~0x300`; return.
  4. Not burrowed: `0x415990`(sprite) starts the decloak effect on images with method 2, 3, 5 or 6 (`0x40ed30`) and applies the same dirty marking; status becomes `(status & ~0x100) | 0x200`. The subunit `+0x70`, if any, gets the same `0x415990` call and status change.
- Callers/callees: `0x425050` (unit removal), `0x42fa70`, `0x434310`.
- Prior evidence: [pixel effects](../native-pixel-effects.md) (decloak callback that later finishes the status change through `0x41d4c0`).

### 0x0041d460 `ShufflePlayerColors` — random permutation of the 8 color assignments
- Module: ctxthelp.cpp..cunitinit.cpp · Relevance: render
- Status: specified
- Signature: `__fastcall`, ECX = flag (result of the slot-setup function in the caller).
- Behavior: Returns unless byte `0x67294a` is 0 or ECX is nonzero. Builds a local byte list `L = [0,1,…,7]`. Then for `i = 7` down to `0`: `k = Random(0, i)` through the ranged RNG `0x478270`(ECX = 0, EDX = i, source 28); `0x5264fc[i] = L[k]`; removes `L[k]` by shifting `L[k+1 .. i]` down with `memmove` (`0x4d2360`, `i − k` bytes). This consumes exactly 8 RNG calls (the last with range 0..0).
- Globals/fields: `0x5264fc` color assignment; `0x67294a` (nonzero suppresses the shuffle unless ECX ≠ 0).
- Callers/callees: tail call from `0x479340` (game slot setup), which skips it when `0x6a5e34 ≠ 0`.
- Prior evidence: [PRNG](../native-prng.md) for the ranged generator.

### 0x0041da50 `CanAttackTarget` — attack legality including detection
- Module: ctxthelp.cpp..cunitinit.cpp · Relevance: simulation
- Status: specified
- Signature: `__thiscall`, ECX = attacker, stack = [target, check detection]; `ret 8`; returns 0/1.
- Behavior:
  1. Returns 0 if the attacker is disabled (status `0x400`, lockdown `+0x117`, stasis `+0x119` or maelstrom `+0x124`), the target is null, the target is invincible (`0x4000000`) or the target sprite is hidden (flag `0x20`).

  6. Queen 0x2d / Matriarch 0x31: returns `0x41fed0`(target) (infestable Command Center).
  7. Arbiter 0x47 with an AI record: returns 0.
  8. Airborne target: returns `0x5213a8[W.type] ≠ 0x82`; otherwise `0x41fc20(W) ≠ 0x82`.
- Callers/callees: 33 callers; the core legality test of all attack paths.
- Prior evidence: [combat AI](../native-combat-ai.md) (special predicates now resolved), [attack orders](../native-attack-orders.md).
