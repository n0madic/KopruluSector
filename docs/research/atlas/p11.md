# P11: Protoss power and spells, hallucinations, unit save, target selection, spell AI, cloaking and addons

This package covers the end of the object between `cunitinit.cpp` and `cunitprotoss.cpp`, all of `cunitprotoss.cpp` and `cunitsave.cpp`, and the start of the object between `cunitsave.cpp` and `cur.cpp` (`0x42f9e0`–`0x435ba0`). Its code falls into eight groups that share CUnit fields and a few file-static globals:

1. **Archon merging and Recall** (`0x42f9e0`–`0x42fc40`, `0x4304d0`). These are the order handlers for CompletingArchonSummon (106), DarkArchonMeld (183) and CastRecall (137). Recall moves units one at a time through the shared placement search.
2. **Psi power** (`0x42fd70`–`0x430670`). The provider list (head `0x665b54`, links `+0xf8/+0xfc`), the power mask built from the `Juice01.grp` frame, the power predicate, the dirty-flag driven power update, the Psi-field overlay sprites (`+0xd0`) and the save-time relinking of Pylons.
3. **Spell effects** for Disruption Web, Maelstrom, Stasis, EMP, Hallucination, Mind Control and Feedback (`0x4307a0`–`0x4310f0`, `0x433fc0`). They also cover the shared spell-casting gates `0x434130`, `0x434460`, `0x434b80`, `0x434e70`, `0x435020`, `0x4350b0`, `0x435320`, `0x435380`, `0x435530`.
4. **CUnit save/load** (`0x431280`–`0x431400`, `0x434b20`, `0x434e30`): used-slot map, pointer packing, list heads.
5. **Detection** (`0x4316b0`, `0x4318f0`, `0x431a90`, `0x432560`, `0x4325a0`, `0x434ac0`) and **cloaking** (`0x4340d0`–`0x434310`, `0x434710`, `0x4348c0`, `0x434900`, `0x434da0`).
6. **Target acquisition** (`0x4319d0`, `0x431b70`, `0x431c40`, `0x432280`, `0x433910`, `0x433c50`). These are covered by [combat AI](../native-combat-ai.md). The group also holds the nearest-unit searches for Medics, Spider Mines, resource depots, mineral fields, powerups and addons.
7. **AI spell target selection** (`0x432bf0`–`0x433df0`). These are the selectors called by the reaction-spell dispatcher `0x48d3a0` and their callbacks. Many callbacks are compiled as unnamed code inside the gaps after atlas functions; each is described under the entry whose address range contains it.
8. **Timers, energy, addons**: the eight-tick spell-timer service, max energy, Nuclear Silo training, addon attach/detach and the embedded PlaceAddon/BuildAddon handlers.

## Entries

### 0x0042f9e0 `OrderCompletingArchonSummon` — order 106 (CompletingArchonSummon)
- Module: cunitinit.cpp..cunitprotoss.cpp · Relevance: simulation
- Status: specified
- Signature: `__fastcall`, ECX = unit; no return value.
- Behavior: Switches on order state `+0x4e`.
  - State 0: calls the build-timer step `0x41a540`. That step returns 1 only when WORD `+0xac` is already 0. Otherwise it decrements the timer by 1, or by 16 with the operation cwal cheat bit `0x2` of `0x5432fc`, clamping a negative result to 0, and returns 0. On a return of 1 the order clears sprite flag `0x80` (IScript no-break) in `sprite+0xe`. It then plays sprite animation 0 (Init) with force 1 through `0x417220`(ECX=sprite) and sets state 1.
  - State 1: acts only when order-signal bit `0x04` (`+0x4f`) is set. It then sets status `0x20000` (can-move) and clears the signal bit. It reinitializes movement through `0x42c7e0` and restores the button set to the unit type through `0x422f00`(ECX=unit, `+0x64`). It refreshes the status UI with `0x4a7ed0` and requests the completion voice with `0x446650`. It appends the type's DAT human-idle order (`0x520e38[type]`) to the order queue through `0x429eb0`(order, 0). Finally `0x429d00` clears status `0x1000` (order not interruptible) and finishes the order through `0x42a5a0`.
  - Other states, or state 1 without the signal: nothing.
- Globals/fields: `0x5432fc` cheat word; unit `+0x4e/+0x4f/+0x64/+0xac/+0xdc`; sprite `+0xe`.
- Callers/callees: main-order dispatcher `0x439420` (table entry for order 106).
- Prior evidence: none. OpenBW's `order_CompletingArchonSummon` has the same structure.

### 0x0042fa70 `OrderDarkArchonMeld` — order 183 (DarkArchonMeld)
- Module: cunitinit.cpp..cunitprotoss.cpp · Relevance: simulation
- Status: specified
- Signature: `__fastcall`, ECX = unit; no return value.
- Behavior:
  1. Partner = order target `+0x5c`. The partner must be nonnull, have the same owner `+0x4c`, be in order `0xb7` itself, and target this unit (`partner+0x5c == unit`). Otherwise the order stops movement through `0x43a4e0` and finishes through `0x42a5a0`.
  2. If status `0x100000` (ground unit) is set, the order calls `0x4229a0`(ECX=unit, radius = (`+0x3c` × 2) >> 8 (arithmetic), partner). That is a bounding-box proximity test against the partner. When it succeeds, the order clears `0x100000` and prepends ResetCollision (order 150) through `0x429b20`.
  3. d = approximate distance `0x405cf0` between the two sprite centers (signed WORD `sprite+0x14/+0x16`).
  4. If d > 20: if the order state is nonzero and movement state `0x41a250` returns 2 (at the move target and status `0x80000` immovable), the order stops and finishes as in step 1. Otherwise it sets state 1. Because d > 20 also means d > 19, it always moves toward the partner's sprite position through `0x438b80`, which does nothing while recent-order timer `+0xe3` is nonzero. The code also contains a midpoint branch (signed `/2` of the coordinate sums), taken only when d ≤ 19; that branch can never run here.
  5. If d ≤ 20 (merge):
     - Merge status effects from the partner (`0x42f3f0`): each timer field becomes the larger of the two values; this covers `+0x112` WORD and `+0x114..+0x117`, `+0x124`, `+0x119`, `+0x11a`. When the partner's irradiate timer `+0x118` is larger, the order also copies `+0x11c` (irradiating unit) and `+0x120` (irradiating player). It ORs the masks `+0x121/+0x123` and copies the acid-spore count `+0x126` and the 8 bytes `+0x127..+0x12e`, plus `+0x12f`.
     - Morph into unit type 63 (Dark Archon) through `0x424ad0`. Decloak with sound 274 through `0x41d360`.
     - Clear sprite flag `0x80`, then force animation 13 (SpecialState1).
     - Set button set 228 with `0x422f00`(228); that write always succeeds for 228. Refresh the UI with `0x4a7ed0`.
     - `killCount +0x8f` += partner's kill count (byte, wraps). Energy `+0xa2` = `0x3200` (50.0).
     - Kill the partner through `0x425700`: user-action bit `0x04` in `+0x93`, then the Death order `0x42a4d0`.
     - Clear status `0x20000`, reinitialize movement through `0x42c7e0`, and issue order 106 (CompletingArchonSummon) through `0x42a2c0`.
- Globals/fields: unit `+0x3c +0x4c +0x4e +0x5c +0x8f +0xa2 +0xdc +0xe3`, status timers `+0x112..+0x12f`.
- Callers/callees: `0x439420` (order 183). The ordinary Archon warp (order 105) is `0x42f830`, outside this package.
- Prior evidence: none. OpenBW's merged `order_ArchonWarp` matches these Dark Archon thresholds (20/19).

### 0x0042fc40 `OrderCastRecall` — order 137 (CastRecall)
- Module: cunitinit.cpp..cunitprotoss.cpp · Relevance: simulation
- Status: specified
- Signature: `__fastcall`, ECX = caster; no return value.
- Behavior: Let `cost` = WORD(`0x51f892` << 8). The value at `0x51f892` is the techdata energy column `0x51f868` entry 21 (Recall); the shift is done in 16 bits.
  - State 1:
    - If main-order timer `+0x54` is nonzero, nothing happens.
    - Otherwise the order clears the recalled flag `0x665b68`. It runs the square query `0x442b20`(ECX=x `+0x58`, EDX=y `+0x5a`, radius 64, callback `0x4302c0`, param caster). That query visits each candidate in spatial order until a callback returns nonzero.
    - If `0x665b68` became nonzero, it plays sound 552 + (raw RNG `0x478200`(source 18) & 1) at the caster through `0x446940`(ECX=sound, EDX=caster, 1, 0).
    - Finally it finishes the order (`0x42a5a0`).
  - Any other state (the initial state is 0):
    - If `0x434b50`(caster, cost) reports insufficient energy, the order shows stat_txt string `0x360 + race`. The race is the result of `0x414550` on the caster's type. The string is fetched by `0x4a7d70` and shown to the owner through `0x46ae50`(ECX=text, EDX=owner); then the order finishes.
    - Otherwise it spends `cost` with `0x435300`; the gathering cheat skips the debit.
    - If a target unit `+0x5c` is set, it copies that unit's sprite position into `+0x58/+0x5a`.
    - It creates a lone sprite 379 (Recall field) at the point with owner 0 (`0x417b80`). On success that sprite's elevation = caster's sprite elevation + 1, and its visibility is initialized (`0x417e50`).
    - It plays sound 550 + (raw RNG source 17 & 1) at the point through `0x446a20`(ECX=sound, EDX=1, stack: packed point, 0).
    - It sets timer `+0x54` = 22 and state 1.
  - Embedded callback `0x4302c0` (ECX = candidate, EDX = caster; returns 0, so the visit continues): the candidate is skipped when its sprite is hidden (`0x20`), its owner differs, it has DAT Building (`0x521660` bit `0x1`), status invincible `0x4000000` or burrowed `0x10`, its type is 35 Larva, 36 Egg or 97 Lurker Egg, it is a hallucination (`0x40000000`), or it is the caster. Otherwise `0x4304d0`(candidate, caster) teleports it at once. Units are recalled one at a time during the visit, so earlier arrivals occupy space seen by later placement searches.
- Globals/fields: `0x51f892`, `0x665b68` (Recall/teleport success flag), unit `+0x4e +0x54 +0x58 +0x5a +0x5c +0xa2`.
- Callers/callees: `0x439420` (order 137). Callees: `0x434b50`, `0x435300`, `0x4304d0`, `0x442b20`.
- Prior evidence: [AI opcodes](../native-ai-opcodes.md) (the AI recall wrapper uses the same `0x51f892` threshold and order `0x89`).

### 0x0042fda0 `HideAllPsiFieldOverlays` — ensure and hide every power-field overlay
- Module: cunitprotoss.cpp · Relevance: render
- Status: specified
- Signature: no arguments.
- Behavior: Walks the power-provider list from head `0x665b54` through `unit+0xfc`. For each provider:
  1. If overlay `+0xd0` is null, it runs an inline copy of `0x42f270`. That copy creates sprite 321 (Psi field) at the provider's sprite position, owner 0, through `0x4154a0`, and stores the result in `+0xd0`. On failure it skips to the next provider. On success it sets sprite elevation `+0xd` = 1. Then, when not in replay mode (`0x67cc90 == 0`) and the provider's owner is local player `0x508d50`:
     - if the fields-shown flag `0x665b64` is set, the overlay gets visibility mask `0x672668` (`0x417280`);
     - otherwise, if the provider's sprite is selected (flag `0x08`), `ShowAllPsiFieldOverlays` (`0x430320`) runs;
     - otherwise, and for non-local providers, the overlay is marked hidden with visibility 0.
  2. In every case where an overlay exists, it then sets sprite flag `0x20` (hidden) and visibility 0 via `0x417280`(0). Visibility 0 marks the images dirty when the mask changes.
  - Finally `0x665b64` = 0.
  - Quirk: a provider without an overlay, local and selected while the flag is 0, calls `0x430320`. That call re-shows the overlays of providers already processed earlier in the list, and those stay visible.
- Globals/fields: `0x665b54` provider list, `0x665b64` overlays-shown flag, `0x67cc90` replay mode, `0x508d50` local player, `0x672668` local visibility mask.
- Callers/callees: `0x423000` (unit deselection; it calls this only for a completed Pylon owned by the local player, outside replay mode) and `0x47d580` (building-placement cursor teardown).
- Prior evidence: none.

### 0x00431400 `SaveUnits` — write the CUnit table to a save game
- Module: cunitsave.cpp · Relevance: simulation
- Status: specified
- Signature: ECX = FILE; returns 1 on success, 0 on any write failure.
