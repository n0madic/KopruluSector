# P44: FLIC buttons, scroll bars and sliders, blend-table effects, screen layers and presentation, resource DLL, fatal errors, file wrappers, palette fades and Korean glyphs

This package covers `0x4c8860`–`0x4cd310` (117 functions): the end of `flc.cpp`, all of `scrlbar.cpp`, `effects.cpp`, `image.cpp` and `vidblit.cpp`, and the start of the object between `vidblit.cpp` and `font.cpp`. It continues the dialog framework of [P42](p42.md) (control layout, events, user codes, per-type tables, theme metrics) and hands text drawing to the font code described in [native text](../native-text.md). Its pieces are:

1. **FLIC (SMK-backed) buttons** (`0x4c8860`–`0x4c8bc0`, plus the unlisted standard-button handler at `0x4c8c00`): opening the button's Smacker clips into private frame buffers, advancing them on a timer, press tracking with sounds, and the type-14 user-event handler.
2. **Scroll bars and sliders** (`0x4c8d10`–`0x4c9be0`): control types 6 (horizontal) and 7 (vertical). Flag `0x2000000` turns either into a slider. Drawing, track geometry, hit zones, thumb drag, auto-repeat, keyboard, range/position setters and the constructor used by list boxes.
3. **Blend-table effects** (`0x4c9c70`–`0x4ca9b0`): 64 KB palette lookup tables built by nearest-colour search, the 0–100 % opacity scale, two compiled Storm SCode blitters, the effect blit dispatcher and an opacity text wrapper.
4. **Intrusive list helpers** (`0x4cab80`–`0x4cac30`) used by the dialog and timer lists.
5. **Screen layers, dirty grid and presentation** (`0x4cac50`–`0x4cb6d0`): the 40×30 dirty-tile grid, the 8 screen layers, the per-frame refresh, cursor background save/restore, the console overlay mask and primary-surface blits.
6. **Resource DLL helpers** (`0x4cb710`–`0x4cb840`), the bounded `snprintf` (`0x4cb860`) and the debug `crash` trigger (`0x4cb890`).
7. **Crash reporter and error log** (`0x4cb8a0`–`0x4cca70`, except `0x4cc190`–`0x4cc4c0`): excluded.
8. **Fatal error and process exit** (`0x4cc190`, `0x4cc290`, `0x4cc320`, `0x4cc340`) and **file wrappers** (`0x4cc370`–`0x4cc4c0`).
9. **Line primitives and palette** (`0x4ccb30`–`0x4cd070`): mostly covered by [pixel effects](../native-pixel-effects.md) and [palette bootstrap](../native-palette-bootstrap.md); this package adds the UI colour index table, the exact fade timing and signatures.
10. **Text** (`0x4cd080`–`0x4cd310`): the line breaker `0x4cd100` (wrapping mode covered by [native text](../native-text.md)) and the GDI-based Korean glyph renderer.

## Data model

**Controls and events** follow [P42](p42.md#control-and-dialog-data-model): `+0x04..+0x0a` s16 rect (left, top, right, bottom, inclusive), `+0x18` flags, `+0x20` s16 ID, `+0x22` type, `+0x26` u32 user value, `+0x2a` interact procedure, `+0x2e` draw procedure, `+0x32` parent. Events: `+0x00` u32 user code, `+0x04` u32 parameter, `+0x08` u16 key, `+0x0c` u16 type, `+0x0e/+0x10` cursor. Helpers used here: `0x4c29d0`(ECX = control, EDX = event, stack = out point) cursor relative to the parent dialog (the control itself when it is a dialog); `0x4c2a00`(ECX = rect, EDX = point) inclusive point-in-rect; `0x4c2840` mark dirty; `0x4c2540`(ECX = control, DX = user code, stack = parameter) send a type-14 user event; `0x4c3370`(ECX = control, EDX = event type) capture an event type (the previous captor gets user code 6); `0x4c3770` release all captures and press slots that name the control; `0x4c3570` start a 30 ms hotkey press slot; `0x4c3740`(ECX = n) call the control sound hook `0x6ce664` with n (0 mouse enter, 1 press, 2 scroll-bar click); `0x4c1e90` default control procedure; `0x4c2640` focus highlight bit `0x1000`; `0x4c3d60`/`0x4c46d0`/`0x4c43e0`/`0x4c4200` theme frame, transparent theme frame, three-part bar and focus outline ([P42](p42.md#0x004c3d60-drawthemeframe)).

**Scroll-bar fields** (types 6 and 7): `+0x36` change callback (fastcall, ECX = `+0x26` user value), `+0x3a` s16 position, `+0x3c` s16 minimum, `+0x3e` s16 maximum, `+0x40` s16 pending step (delta added on each repeat), `+0x42` u32 current action flag, `+0x46` u8 page step, `+0x47` u8 repeat countdown, `+0x48` u8 slider thumb frame, `+0x49` u8 slider tick step, `+0x4a` s16 thumb offset while dragging. Flags: `0x40000000` decrement arrow pressed, `0x20000000` increment arrow pressed, `0x80000000` dragging the thumb, `0x08000000` page-decrement active, `0x04000000` page-increment active (the five action flags; `0x4c9630` clears them all with mask `0x13ffffff`), `0x2000000` slider style.

**Hit-zone tables.** Zone (from `0x4c9790`): 0 outside, 1 decrement arrow, 2 increment arrow, 3 thumb, 4 track before the thumb, 5 track after the thumb, 6 (unreachable). Action flags `0x4f11d0[7]` = {0, `0x40000000`, `0x20000000`, `0x80000000`, `0x08000000`, `0x04000000`, 0}. Step table `0x50ef78` (7 × s16) = {0, −1, +1, 0, −page, +page, 0}; entries 4 and 5 (`0x50ef80`, `0x50ef82`) are rewritten from `+0x46` on every mouse-down.

**Theme metrics used** (u16, set by `0x4c31d0` from the theme GRP, see [P42](p42.md#0x004c2ca0-createtheme)): `0x6ce6fc`/`0x6ce6f4` width/height of frame 22 (left arrow), `0x6ce700`/`0x6ce6f8` width/height of frame 16 (up arrow), `0x6ce704` height of frame 29 (vertical track piece), `0x6ce708` width of frame 32 (horizontal track piece), `0x6ce70c`/`0x6ce710` width/height of frame 28 (thumb), `0x6ce74c` width of frame 92 (slider track piece), `0x6ce750`/`0x6ce754` width/height of frame 99 (slider thumb), `0x6ce758` width of frame 97 (slider tick). Scroll-bar art frames: horizontal 22–24 left arrow (disabled/normal/pressed), 32 track start, 33 track middle, 34 track end, 25–27 right arrow, 28 thumb; vertical 16–18 up arrow, 29/30/31 track, 19–21 down arrow, 28 thumb; slider 91 (disabled) or 94 three-part track, ticks 97 (disabled) or 98, thumb 99 (disabled) or `+0x48` (default 100).

**UI colour indices** `0x6d2368[26]`, filled by `0x4cccb0` with the nearest palette index (callback `0x4666c0`, which skips reserved entries) to the colours `0x50f0f8[26]` (0x00BBGGRR): 0–15 grays from `ffffff` down to `000000` in steps of `10` per channel (`e0e0e0`, `d0d0d0` … `101010`, `000000`); 16 `0xe34b00` (blue, `0x6d2378`, focus outlines and enabled slider), 17 `0x4fffff` (yellow), 18 `0x2be300` (green), 19 `0x157100` (dark green), 20 `0x0000cf` (red), 21 `0x1892ff` (orange), 22 `0xba185a` (purple), 23 `0x243c5c` (brown), 24 `0xae54dc` (pink), 25 `0xffff00` (cyan). `0x6d2370` (index 8, `0x707070`) is the disabled slider colour.

**Blend effects.** Opacity level map `0x6cfd28[101]` (s32): level(p) = ⌊7p/100⌋ for p = 0…100, so 0–14 → 0, 15–28 → 1, 29–42 → 2, 43–57 → 3, 58–71 → 4, 72–85 → 5, 86–99 → 6, 100 → 7. Level 0 draws nothing, 7 is an opaque keyed copy. Three 64 KB blend tables `0x6cf7b4[3]`; a level L uses slot L − 1 for L ≤ 3 and slot 6 − L for L ≥ 4 (levels 3 and 4 share slot 2). A table built with weight w (`0x4c9c70`) holds `T[r·256 + c]` = nearest palette entry to `(w·P[c] + (8 − w)·P[r]) >> 3` per channel. Compiled blitters ([S01](s01.md#0x1500cd60-scodecompile-ord-331--compile-a-prologloop-pair)): handle `0x6cfbd4` writes `dst = T[src | dst << 8]` (source weight w/8) and handle `0x6cfbd8` writes `dst = T[dst | src << 8]` (source weight (8 − w)/8). Levels 1–2 use `0x6cfbd4`, levels 3–6 `0x6cfbd8`. Other tables: `0x6cfbd0` keyed copy (row 0 identity, rows j ≥ 1 all j, so source 0 is transparent) and `0x6cfbcc` single-colour blend (same initial content; one row is rewritten on demand). State: `0x6cf7c0` cached palette (1024 bytes), `0x6cfbc0[3]` slot-built flags, `0x6cfbc4` initialized, `0x6cfc20[256]`/`0x6cfd20` excluded palette indices (ascending) and count, `0x6cfbdc` draw directly to the locked primary surface, `0x6cf7b0` single-colour set selector (0 = A, 1 = B), set A = level `0x6cfbc3` + colour index `0x50ef88`, set B = level `0x6cfd24` + colour index `0x50ef90`, `0x50ef8c` single-colour table stale, `0x6d06c0`/`0x6d06c4` row and level currently patched into `0x6cfbcc`, `0x6cfbc8`/`0x50f0d0` level and colour row cached in `0x6d06c8[8]`, `0x6d02bc` squares table (`0x6d02bc + 4k` = k² for k = −255…255, built once, flag `0x6d06bc`), `0x6cfbe0` the 0x40-byte SCode execute block (`+8` width, `+0xc` rows, `+0x10` destination adder, `+0x14` source adder, `+0x18` destination, `+0x1c` source, `+0x20` table).

**Effect descriptor** (passed to `0x4ca420`/`0x4ca660`): `+0` u32 flags (`1` build `0x6cfbd0`, `4` build `0x6cfbcc`), `+4` u32 excluded-index count, `+8` u8[256] excluded indices, `+0x108` u32 opacity count, `+0x10c` u8[] opacity percentages. The game descriptor (`0x47bca0`) has flags 5, the tileset's palette-cycling indices as exclusions and one opacity of 60 % (level 4, slot 2 built with w = 4, an even 50 % blend). Glue screens pass their own descriptor (`0x457f00`) and set colour set A at 80 % (level 5) through `0x4ca820`.

**Screen layers** (see [P06](p06.md), [P42](p42.md#control-and-dialog-data-model)): 8 records of 20 bytes at `0x6d0b90`: `+0` u8 enabled, `+1` u8 flags (`1` redraw requested, `2` redraw every frame, `4` was dirty this frame, `0x20` always draw), `+2/+4` s16 x/y, `+6/+8` s16 width/height, `+0xc` u32 argument, `+0x10` paint callback (called with `[argument, &bounds]`; ECX = EDX = 0). Layer 0 is the cursor, layer 1 the tooltip, layer 2 dialogs. Screen buffer descriptor `0x6d0b88` {u16 640, u16 480, `0x6d0b8c` pixels}; current target bitmap pointer `0x6d0c40`; current line colour `0x6d0c50`. Dirty grid `0x6d06d0[30][40]` (one byte per 16×16 tile). Cursor background: save bitmap `0x6d0b80` {u16 w, u16 h, `0x6d0b84` 0x900-byte buffer}, saved rect `0x6d0c30` (s16 l, t, r, b) and size `0x6d0c38`, valid flag `0x6d0c3c`. Full-redraw request `0x6d0c4c`. Black-screen flag `0x50f0f0` (set by fade-out).

**Screen overlays** (the in-game console): Storm list `0x50f0d4` (tail link `0x50f0d8`, head `0x50f0dc`, a value ≤ 0 ends the list) of 0x20-byte nodes `+8` STrans mask, `+0xc`/`+0x10` x/y, `+0x14`/`+0x18` x + w, y + h. Combined mask `0x6d0c44` and its duplicate `0x6d0c48`.

**Resource DLL**: `local.dll` handle `0x6d0c54` (loaded by [P22](p22.md) `0x465a20`), game instance `0x66fd34`, main window `0x66fd28`.

**Palette** ([palette bootstrap](../native-palette-bootstrap.md)): current `0x6d2388`, fade source `0x6d2788`, target `0x6d2b88`, cycle records `0x6d2f88[8]` of 16 bytes (`+0` active, `+1` speed, `+2` counter, `+3` low, `+4` phase, `+5` high, `+8` pattern, `+0xc` pattern count). Upload `0x4cf8c0`(ECX = first entry pointer, EDX = first index, stack = count).

**Text state** ([native text](../native-text.md)): current font `0x6d3020`, font slots `0x6d3024…0x6d3030`, font mode `0x66ccc0`, wrap flag `0x50f160`, current x `0x6d3048`, clip left `0x6d3038`, clip right `0x6d303c`, tab width `0x6d300f`, DBCS lead `0x6d300c`, highlight byte `0x6d3114`, colour row pointer `0x6d3010`, colour rows `0x6d3050 + 8n`.

## Entries

### 0x004c8860 `OpenFlicClip` — open one SMK clip of a FLIC button into a private buffer
- Module: flc.cpp · Relevance: ui
- Status: specified
- Signature: fastcall, ECX = SMK node (`+4` flags, `+0xa` file name, `+0xe` video handle, `+0x16`/`+0x18` s16 w/h, `+0x1a` pixels).
- Behavior:
  1. If w = 0 and h = 0: `SVidPlayBegin`(name, 0, 0, 0, 0, 0, &v); v = 0 → fatal `Could not load "%s"` (`0x4cc190`). `SVidGetSize`(v, &w, &h, 0), `SVidPlayEnd`(v); store w, h (low words).
  2. Allocates the frame buffer (`0x4cb200`, line `0x15f`), clears w·h bytes.
  3. `SVidPlayBegin`(name, pixels, {0, 0, w − 1, h − 1}, {w, h}, 0, `0x21520100` | ((flags & 4) << 16), &`+0xe`) (buffer target, no audio, no skip, ignore palette, preload, unzoomed; node flag 4 adds loop `0x40000`). A null handle → the same fatal error.
  4. `SVidPlayContinueSingle`(handle, 1, 0) renders the first frame.
- Callers/callees: `0x4c8200` (FLIC button initialization).
- Prior evidence: [S01](s01.md#0x15030e20-svidplaybegin-ord-454--open-and-start-a-video), [dialog BIN](../native-dialog-bin.md) (SMK node layout).

### 0x004c89b0 `AdvanceFlicButton` — per-tick SMK playback and hover fade
- Module: flc.cpp..scrlbar.cpp · Relevance: ui
- Status: specified
- Signature: fastcall, ECX = control.
- Behavior: Only when visible. Walks the clip list `+0x42` through a link pointer: `SVidPlayContinueSingle`(clip `+0xe`, 0, &shown). - Callers/callees: `0x458ed0` (glue timer).
