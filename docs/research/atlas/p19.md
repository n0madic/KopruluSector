# P19: Glue screen framework, custom-game/replay creation, the message boxes, the expansion campaign menu and the load-game screen

This package covers `0x455550`–`0x459f0f`: `glucreat.cpp`, the object between `glucreat.cpp` and `gluerror.cpp`, `gluerror.cpp`, the object between `gluerror.cpp` and `glues.cpp`, `glues.cpp`, the object between `glues.cpp` and `glujoin.cpp`, `glujoin.cpp`, and the objects between `glujoin.cpp` and `glulogin.cpp` (the join list and `gluLoad`). Its 98 functions fall into six groups.

1. **Create Game / Play Custom / Load Replay** (`0x455550`–`0x456a40`, 29 functions). `0x455550` runs `rez\gluCustm.bin` offline (glue state 11 Play Custom and 12 Load Replay) or `rez\gluCreat.bin` in multiplayer. It owns the map/replay file list (drawn with `glue\create\iCreate.grp` icons), the map-information labels fed by `glumap.cpp`, the game-type, subtype and speed controls (persisted in the registry), and the computer-slot controls of a single-player custom game. Offline custom games and replays are in scope (`specified`). Multiplayer-only branches are noted where they occur.
2. **Message boxes** (`0x456b50`–`0x457380`, 9 functions). `gluError.cpp` shows OK, two-text OK and OK/Cancel message boxes. While a glue dialog is active they delegate to the MPQ popups of `gluPopup.cpp` (`0x460100`, `0x460230`, `0x460330`). Otherwise they build a dialog from resources (`GLUEOK_BIN`/`GLUEOKCANCEL_BIN` and their `_PCX` images) in the localized module, remapping the image to the current palette.
3. **Glue framework** (`0x4573a0`–`0x458980`, 33 functions). The glue loop `0x457510` (glue state machine `0x66a274`), per-theme resources (cursor, dialog theme, effect and font banks for the twelve `glue\Pal*` themes), the screen background and palette, the gluAll string table, UI sounds, and the slide-in/slide-out animation of glue controls. Only the window-closing callback `0x4574a0` is `excluded`: it runs only in the Battle.net state.
4. **Expansion campaign menu and cinematics** (`0x458b00`–`0x458fc0`, 7 functions). `rez\gluExpCmpgn.bin` (glue state 22), the locked-episode hints, and playback of a cinematic with its prelude.
5. **Join game list** (`0x459000`–`0x4597f0`, 11 functions): `rez\gluJoin.bin` (glue states 10 and 21). This list exists only for multiplayer games, so the group is `excluded`.
6. **Load saved game** (`0x459910`–`0x459ea0`, 9 functions). `rez\gluLoad.bin` (glue state 13) lists, loads and deletes saved games. It also holds two Storm list helpers that the login screen uses. All are in scope.

## Shared data and tables

**Dialog machinery** (as in [P17](p17.md) and [P36](p36.md)). Control fields: `+0x00` next sibling, `+0x04..+0x0b` s16 rect `left, top, right, bottom` (dialogs: `+0x0c` bitmap descriptor `{s16 w, s16 h, ptr pixels}` at `+0x0c..+0x13`), `+0x14` text, `+0x18` flags (bit 0 dirty, bit 1 disabled, bit 3 visible, bit 7 mouse-over, `0x4c00` font size), `+0x20` s16 ID, `+0x22` u16 type, `+0x24` u16 `wUser`, `+0x2a` interact procedure, `+0x2e` draw procedure, `+0x32` parent, `+0x42` first child (dialog). List-box fields: `+0x3a` item-text pointer array, `+0x3e` item-flag byte array, `+0x42` item-data dword array, `+0x46` u8 count, `+0x47` u8 capacity, `+0x48` u8 selected index, `+0x49` u8 row height, `+0x4e` u8 highlighted (cursor) row, `+0x52` item draw callback. Helpers used throughout: `0x4c2200`(ECX = dialog or control, DX = ID) find child; `0x4c2890` show; `0x4c22f0` hide; `0x4c2900`(EDX ≠ 0 ? show : hide); `0x4c2280` disable; `0x4c2910` enable; `0x4c2600`(EDX ≠ 0 ? disable : enable); `0x4c2840` mark dirty; `0x4c2820`(EDX = text) set text and mark dirty; `0x4c2860`(EDX = value) send user code 11 (value changed) to the control; `0x4c2540`(EDX = code, stack 0) send user code to a control; `0x4c25b0`(ECX = dialog, EDX = array, stack = byte size) installs `array[ID − 1]` as the interact procedure of every child with ID ≥ 1 whose array entry is nonzero; `0x4c33a0`(ECX = name, EDX = file loader, stack: bitmap loader, file, line) loads a dialog; `0x4c35c0`(ECX = dialog, EDX = 0, stack = procedure) runs it modally and returns the result; `0x4c2b50` closes a dialog (it does not write `0x6ce6dc`; the caller stores the result there before the close request, [P42](p42.md)). List helpers: `0x4c61d0`(ECX = list, EDX = text, stack = item flags; flag `0x10` copies the text) appends and returns the index or `0xff`; `0x4c7070`(DL = index, stack = value) sets item data; `0x4c6840`(DL = index) gets item data; `0x4c6850`(DL = index) gets item text; `0x4c6830` count; `0x4c6890` selected index or `0xff`; `0x4c7250`(DL = index) selects; `0x4c7230`(DL = 0 suspend, 1 resume) redraw; `0x4c6ef0` clear; `0x4c7090`(EDX = text) select the matching text, returning the index or `0xff`. Default procedures: `0x4c1470` dialog, `0x4c63b0` combo box, `0x4c6480` list box, `0x4c9630` slider, `0x4c82f0`/`0x4c83b0` buttons, `0x4c1860` static text. UI timers: `0x4c5960`(ECX = owner, DX = ID, stack: period ms, callback) creates or replaces a repeating timer, and `0x4c58f0`(ECX, DX) deletes it. A dialog event is `+0` u32 user code, `+4` u32 parameter, `+0xc` u16 type; type 14 is the user event, with codes 0 = activate, 1 = destroy, 2 = button activated (the button ID is in `0x6ce6dc`), 10 = post-load initialization, 11 = value/selection changed, and `0x405` = slide-in finished.

## Functions

### 0x00455550 `RunCreateGameScreen` — Play Custom, Load Replay and multiplayer Create Game
- Module: glucreat.cpp · Relevance: ui
- Status: specified
- Signature: `__fastcall`, ECX = replay mode (glue state 11 → 0, 12 → 1); no return value.
- Behavior:
  1. `0x668f98` = ECX. It loads the dialog through `0x457a20`: `rez\gluCustm.bin` when the multiplayer byte `0x672664` = 0, else `rez\gluCreat.bin` (`0x668a58`). It loads `glue\create\iCreate.grp` whole (`0x444a60`, "gluCreat.cpp" line `0x593`) into `0x668f8c`, sets `0x668a5c` = 1 and runs the dialog with procedure `0x4550e0` (P18).
  2. Result 12 (OK). In multiplayer the state becomes 3. Offline: if the game is not Use Map Settings (`0x447db0`(0) = 0) or a replay is selected (`0x67cc90` ≠ 0), game state WORD `0x6662b8` = 1 (start at once). Otherwise the state comes from the local slot's race byte `0x6726d1 + 36·0x508d50`: 0 → 8 (Zerg ready room), 1 → 7 (Terran), 2 → 9 (Protoss). Any other race leaves the state unchanged, so the loop re-enters this screen.
  3. Results −3 and 13 (cancel). `0x67cc90` = 0 and the loaded replay is freed (`0x4808d0`). Offline: state = 22 if Brood War (`0x536720` ≠ 0), else 6. Multiplayer, by provider `0x475a10()`: `'MODM'` or `'MDMX'` → 20, `'BNET'` → 4, `'LBCS'` → 21, anything else → 10.
  4. Any other result: state 0.
  5. Finally `0x457b50`, frees the GRP (`0x444ca0`, line `0x5cc`), `0x668a5c` = 0.
- Callers/callees: glue loop `0x457510`.

### 0x00455850 `DrawMapListItem` — owner-draw for the file list
- Module: glucreat.cpp..gluerror.cpp · Relevance: ui
- Status: specified
- Signature: `__fastcall`, ECX = list, DL = item, stack (rect\*, s16 x offset, s16 y offset), `ret 0xc`.
- Behavior: `hot` = (item = list `+0x4e`). Icon frame: if `0x45beb0` finds the item's entry, flags = 8 (directory) → `hot`, else 3 + `hot`. If the entry is not found, the frame is 0. It reads the frame size from `iCreate.grp` (`0x4cf570`). The icon is drawn (`0x4c3c70`, flags `0x2000`) at x = rect.left + x offset and y = rect.top + ((rect.bottom − rect.top + 1)/2 − frameH/2) + y offset, where each `/2` rounds toward zero. The text starts `frameW + 2` further right. It uses text style 3 + `hot` (`0x4ce250`), layout-flags byte `0x6d300e` = `0x11` ([P45](p45.md)), and clip rect `0x6d3038..0x6d303e` = rect shifted by (text x, y offset). The item text is cut to the characters that fit in (rect.right − rect.left) − text x + 1 pixels (`0x4cdd30`), copied with SStrCopy (limit fit + 1, at most 260), and drawn by `0x4cdf20`.
- Callers/callees: installed as list `+0x52` by `0x455aa0`.

### 0x004559d0 `MapListProc` — file list control (ID 5)
- Module: glucreat.cpp..gluerror.cpp · Relevance: ui
- Status: specified
- Signature: `__fastcall`, ECX = list, EDX = event; returns the handled flag.
- Behavior: Only user events are special (byte map `0x455a90`, jump table `0x455a7c`). Code 0: `0x455aa0`, then default `0x4c6480`.
