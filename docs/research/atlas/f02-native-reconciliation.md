# F02: Reconciliation of earlier specifications

This pass reconciles the earlier contract specifications (`docs/research/native-*.md` and their evidence JSON) with the function atlas. Its inputs are the contradictions reported by atlas packages, the follow-ups that name a `native-*.md` document, and four open items that the atlas resolved. Each item was re-checked against the capstone disassembly of the exact executable (SHA-256 `94dea44898a3934cdfae2a8149c0044db8ad1af4b4bc54306cdca3b1612d6ed0`) and against the earlier document's executed probe inputs and outputs. Status-bit questions follow the verdicts of [V01](v01.md). No original code was run. Atlas package documents were not edited.

Each corrected passage in a native document carries the note "Corrected after the function atlas" (or "resolved by the function atlas") with a link to the atlas entry. Generated evidence values (probe outputs, case IDs, input keys, hashes) were left unchanged.
