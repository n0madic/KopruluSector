# Original-game research completion ledger

The research objective is to finish every original-game investigation needed to implement the faithful Defold remake, leaving no unanswered behavior or data-format questions. The inherited implementation scope is all six StarCraft/Brood War campaigns, on the local **1.17.0.1** data profile, with general engine rules and no mission-specific patches. This ledger preserves that objective across research batches. Its domain audit is closed by the function atlas; see the gate below.

Research resumed on 2026-10-10 and finished with the [function atlas](atlas/README.md): a static specification of every function in the exact executable, reconciled with the earlier executed contracts. The [pause checkpoint](pause-checkpoint.md) is historical.

Research completion means an implementer can obtain the required inputs, reproduce each algorithm's state transitions and exceptional cases, and validate its campaign-facing behavior without substituting an untested guess. A dispatch pointer, an opcode inventory, a modified reference implementation, or a passing leaf probe does not close an unresolved callee.

The implementation plan also contains future product and platform choices. Target-device selection, touch layout, and distribution choices are not hidden properties of StarCraft to recover from its executable. The rows below concern original data and behavior required by that plan.

## Gate for marking the research complete

The gate below replaces the earlier Wine-based observation gate: StarCraft 1.17 cannot run reliably under Wine on the research host, and the user declined a VM (2026-10-10). Runtime observation of the complete game is instead provided by the Unicorn full-game emulator (item 6).

1. Each R01–R37 row names the atlas documents that specify its code and data, and the earlier contracts that executed it. **Met.**
2. Every function in `StarCraft.exe` 1.17.0.1, every Storm import and every `Local.dll` function has a status of `specified`, `covered`, `excluded` (with reason) or `library`, and no entry states undetermined behavior. **Met** (`verify_atlas.py`: 50 packages, 6082 objects, 0 errors). Every function start, including code that Ghidra merged into a neighbour, has its own entry ([E01](atlas/e01.md); scans in the [F03](atlas/f03-final-fixes.md) appendices).
3. Contradictions between sources are resolved from the disassembly of the exact executable, with executed probes kept authoritative on their inputs. **Met** ([V01](atlas/v01.md), [F01](atlas/f01-corrections.md), [F02](atlas/f02-native-reconciliation.md), [F03](atlas/f03-final-fixes.md)).
4. Evidence levels stay labeled: executed probes (level 2), static specifications (level 3), reference projects only as hints. **Met.**
5. The campaign data reach no unknown code path: excluded code is unreachable offline, and data formats (DAT, TBL, CHK, GRP, PCX, WAV, SMK, tilesets) are specified with byte-exact checks. **Met.**
6. The complete original game was observed by executing the original `StarCraft.exe` and `storm.dll` (with `local.dll`, `standard.snp` and `smackw32.dll`) in Unicorn, with host code only at the Windows API boundary ([full-game emulation](full-game-emulation.md), [evidence](evidence/full-game-emulation.json)). Observed so far:
   - Boot to the main menu, and all 64 missions of the six campaigns for 3,000 frames without faults.
   - All six campaign chains through victory, the score screen and campaign advance to their end, and defeat paths.
   - Four 20,000-frame runs that are byte-identical when repeated.
   - Scripted play through synthetic window messages:
     - command-card buttons and hotkeys;
     - building placement and add-ons;
     - control groups and view hotkeys;
     - targeted orders, spells, rally points and minimap clicks;
     - training and construction cancel with refunds;
     - transport load and unload;
     - burrow;
     - the in-game menu;
     - PrintScreen through Storm's PNG encoder.
   - Map-trigger victories won through scripted play with no cheats, one for each race:
     - Terran: Wasteland.
     - Zerg: Among the Ruins, won at frame 21,785.
     - Protoss: First Strike, won at frame 21,614.
     A cheat-free attempt at Protoss mission 6 failed; the cause is identified and recorded in the emulation document.

Every one has an entry, and the 24 executed `excluded` functions are start-up or offline no-ops with their reasons rewritten. **Met.** The simulation does not read the wall clock: trigger time is counted in frames, and wall-clock readers are limited to pacing, UI, the score-screen and save time, sound and network code (see the time model in that document).
