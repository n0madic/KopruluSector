# ADR 0013: StarCraft: Remastered as the only data source, and its HD art

Status: accepted (2026-10-26). The user approved the plan (inline design document and plan file, 2026-10-26): import every resource the remake needs from a StarCraft: Remastered install alone, the original graphics as well as the HD art, so a player needs one distribution, not two; the HD art is drawn by an HD renderer; HD2 (×2) and HD (×4) are both imported and chosen by scale; enUS only for now; no Carbot skin. Evidence: [Remastered as a data source](../research/remastered.md). Amends `IMPLEMENTATION_PLAN.md` "Scope V1" (CASC/Remastered was outside V1).

## Context

The converter reads a verified Brood War 1.17.0.1 install (profile `bw-1.17.0.1`: StarCraft.exe and five MPQs) and every oracle checks the palette-indexed data it produces. Remastered's CASC storage keeps most of those files byte for byte, some under `SD/`, the enUS locale or another name, grows the tilesets by appending, and holds the rest only in its own formats (RGBA DDS, DXT `*.dds.grp`, WebM, XML and JSON). Its executable's code is encrypted. Measured on 1.23.10.13515 over the 4,376 files the conversion reads: see the research note's table.

## Decision

1. **Sources.** The conversion reads a `Source` (`converter/source.py`): the MPQ `Resolver` (`--data`) or `ScrSource` (`--scr`, `converter/casc/source.py`), which presents a Remastered install as profile `bw-1.17.0.1`'s files under their MPQ paths. No conversion step reads the executable: its requirement tables and the digest of its VCOD resource are in `defs/` (`defs/dat/requirements-*.json` `words`, `defs/chk/*.json` `vcod_resource.sha256`), checked against the executable by `test_dat` and `test_chk`.
2. **The manifest.** `defs/scr/inputs-<profile>.json` lists every file the conversion reads from the 1.17 install with its size and SHA-256, the names it looks for and does not find (`absent`) and the files it cannot read (`unreadable`): hashes and names only. `python3 -m converter scr-manifest --data DIR` runs the whole conversion over a recording source and writes it.
3. **Lookup and status.** `ScrSource` tries, for an MPQ path, the moved-files table, then the prefixes `SD/`, the root, `locales/enUS/Assets/SD/`, `locales/enUS/Assets/`, and rebuilds what is derivable (a grown tileset's prefix of the manifest's size, with the CV5 groups Remastered filled in emptied again; `.vx4` from `.vx4ex`). Each file gets a status, written to `reports/scr-import.json`: `exact` (a copy has the manifest's hash), `derived` (rebuilt to it), `differs` (no candidate reaches it; the first copy is used), `unlisted`, `unreadable`, `missing`. A name absent or unreadable in 1.17 stays so, so the conversion sees 1.17's data set.
4. **What 1.17 alone has.** Where Remastered has no exact copy the SC:R build uses Remastered's data as an `approximation` (plan §8): portraits and glue movies (lossy WebM), strings Remastered edited, frames kept only in DXT, the music and mission speech it re-recorded. Data that is not art, text or audio (the dialogs' numeric structure, string id order) may go into `defs/` like the interface tables. The 1.17 install stays the reference of every oracle and golden.
5. **HD art.** Imported from the user's install only, never shipped: `.anim` sprites (diffuse, team colour mask) and HD terrain (one tile per megatile) for HD2 and HD, drawn by an RGBA world pass at the window's resolution under the palette-indexed interface (`--graphics original|hd|auto`). The simulation and the index oracles do not change; HD is an `approximation` (ADR 0011 point 5).

## Stages

- **R0** (2026-10-26): exe-free conversion, `Source`, `ScrSource` with the exact, moved and tileset files, the manifest, `reports/scr-import.json`, `compare_outputs` (containers of two sources section by section). On 1.23.10.13515: 2,823 exact and 29 derived of 4,376; `missions --scr` gives the 64 mission containers with the same sections as from 1.17.
- **R1** (2026-10-27): rebuilds from Remastered's own formats (`converter/casc/rebuild.py`), judged by the manifest's extras (`rebuild.describe`: an image's index plane, colour plane, palette and varying PCX header bytes; a dialog GRP's frame table; an SMK's header and the PCX palette its colours match):
  - **PCX** from the SD RGBA DDS with the palette of a PCX of the same palette group that Remastered keeps exactly (alpha 0 → index 0, an opaque colour → its lowest index, a translucent one → its highest, else the nearest); block padding cut, an HD image sampled, a console's rows padded above. Statuses `derived` (bytes equal), `equivalent` (indices and palette), `colour-equal`, `approximation`.
  - **TBL**: `stat_txt` is Remastered's TBL with 1.17's last 8 strings from its XML (exact); the others from the XML by string id, inner NULs at the recorded positions (`defs/scr/texts-<profile>.json`: ids and NUL positions, no text).
  - **Dialog BIN**: each dialog's skeleton (its bytes with every string zeroed, in the texts file) with its texts: names (dialog, bitmap and SMK file names) as recorded, the rest from Remastered's `RC3.xml` (equal texts in order, else an equal text anywhere, else its own entry if at least 0.6 similar; a replaced label such as "Collections" for "Campaign Editor" stays empty); a longer text is appended with its pointers moved. 52 of 69 equal the originals.
  - **Dialog GRPs** (the glue's `Dlg.grp`): the frame table recorded, frames from `SD/glue/<theme>/dlg.dds.grp` (DXT1, another theme's when its own is missing) in the theme's palette; the glue's `arrow.grp` is the game's `cursor\arrow.grp` in the theme's palette.
  - **SMK**: KPV1 from the WebM (`docs/formats/kpd.md`, `kp_smk.c`).
  - On 1.23.10.13515: 2,837 exact, 227 derived, 6 equivalent, 19 colour-equal, 605 approximations (549 movies, 25 dialog GRPs, 17 dialogs, 9 PCX, 5 TBL), 682 Remastered copies that differ (674 WAVs, 7 briefing texts, 1 PCX); none missing. Every command runs from `--scr` alone (`tools/product.sh` takes `KOPRULU_GENERATED`), and `kp_load_check` loads all 304 containers under ASan. Against the 1.17 conversion, the containers whose sections differ are `portraits.kpd`, `ui.kpd`, `strings.kpd`, `sounds.kpd` (`MUSL`, the re-recorded music) and the sounds of the packs and missions (the OGG streams' serials follow the output directory, and the mission speech was altered); the missions, rules, scripts, tilesets, atlases and `grpmeta` equal.
- **R2** (2026-10-27): `python3 -m converter hd` (`converter/emit/hd.py`, `formats/anim.py`): HD packs beside the SD packs, frame for frame, and HD tilesets (docs/formats/packs.md). On 1.23.10.13515 every one of the 832 GRPs has HD frames (830 anims, the counts equal the GRPs'), every tileset one tile per megatile.
- **R3** (2026-10-27): the HD world (`kp_gfx`; `--graphics original|hd|auto`, auto from a scale of 2 when the art is there: HD above a scale of 3 on a computer, else HD2; the development checks keep the original). `kp_present/kp_hd.c` loads the HD packs (their frame table shares the SD table's global frames) and makes an atlas of the megatiles the map uses; `kp_gfx` draws into an RGBA target of the logical screen times the art's scale, with premultiplied colour and the ranks as depth: the HD terrain, the overwriting images with their owner's team colour (Remastered's mix(c, c × team, mask), the player's brightest tunit colour) and the hallucination colours, the destination images (shadows darken by half, blend banks' glows add, trans50 and cloak blends at half), the distortion images faint, the fog as a smooth darkening from its levels, the health bars from the bars texture; then the canvas and the cursor over it at the window's resolution (translucent canvas texels at half) and the vector text. BC1/BC3 pages are uploaded as blocks where the context takes S3TC (`kp_gb_compressed` tries it), else decoded (`kp_present/kp_bcn.c`). The choice is made when the world is built (a game started at once is laid out first).
- **R4** (design approved by the user, 2026-10-27, inline design document; ETC2/ASTC kept as a sub-stage of its own at the user's request): R4a streaming of the HD pages, R4f ETC2/ASTC for phones, R4c the palette's fades and the water on the HD world, R4d the HD interface, R4e HD portraits and glue movies, R4b web HD2. Every failure of the HD path falls back to the SD art of that place.
  - **R4a** (2026-10-27): the HD packs (schema 2) keep each frame's blocks, packed by image into 2048² pages (80–82 % full; HD2 354 MB, HD 1.4 GB). The runtime opens a pack from its header and frames and streams its pages: `kp_present/kp_hd_cache.c` keeps a fixed number of slots (the layers of the HD textures, `KP_HD_BUDGET`: 768 MB on a computer, 384 MB on a phone; `--hd-budget MB`) holding the pages the drawn images show, the least recently wanted page evicted first and never one wanted by the current image data, a page refused a slot waiting `KP_HD_RETRY` changes; `kp_app_hd.c` reads (and, without S3TC, decodes) the pages on a thread, the main thread uploads four a frame, and the first frame with images waits for its own. A frame whose page is not resident, or that has no HD art, is drawn from the SD atlas in its palette colours at the logical scale (its shadow at half). zerg02 in HD (×4) runs in 33 slots of 200 MB (R3 uploaded 1.7 GB); frame medians on macOS: zerg02 HD2 0.43–0.47 ms against the original's 0.64–0.69 ms, bench_combat HD2 0.65–0.75 ms against 0.56–0.64 ms.

## Consequences

- One install is enough; with both, the 1.17 one stays the reference and the manifest shows exactly where the SC:R build departs from it.
- A new Remastered build is checked by the manifest, not trusted: a changed file shows as `differs`.
- The converter needs ffmpeg for Remastered's WebM, as for SMK; the runtime gains no dependency.
